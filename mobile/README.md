# LUMINA 2048 · 触屏网页版

在浏览器里滑动、合并数字，挑战 2048 和更大的方块。支持 iPhone、iPad 与带键盘的浏览器设备。

这是 **Touch v1 网页版**，可添加到主屏幕。iPhone / iPad 原生 App 是另一个版本，网页版不能当作 IPA 安装。

## 开始游玩

1. 在 Safari 打开 [LUMINA 网页版](https://lumina-2048.vercel.app/)。无需注册或登录，打开即可游玩。
2. 等待页面完整加载；需要主屏幕入口时，点「分享 → 添加到主屏幕」。
3. 选择「经典」，在棋盘内向四个方向滑动，或点击方向按钮。外接键盘可用方向键 / WASD。
4. 相同数字会合并成双倍；每次有效移动后通常会出现新方块。到达 2048 后可以继续。

网页资源准备完毕后才可离线游玩。首次使用时请先联网完整加载，再测试从主屏幕离线打开。

## 六种玩法

| 玩法 | 目标 |
|---|---|
| 经典 2048 | 不限步数，挑战更大的数字。 |
| 能力远征 | 六关得分挑战，选能力、攒能量，使用凝时与交换。 |
| 败局重生 | 从败局中腾出空间，六步内恢复至少三个空格；附三道练习。 |
| 每日同局 | 按日期开始挑战，同日期、同顺序的操作可复现落子。 |
| 谜题剧场 | 十二道固定谜题，在限制步数内合成目标数字。 |
| 六十步冲刺 | 用六十次有效移动争取高分。 |

各模式保留独立进度。撤销会恢复步数和随机状态；相同动作不会因撤销而重新抽取落子。提示和自动玩属于辅助，撤销不能清除辅助标记。

## 常用功能

- 提示：查看下一步建议，是否采用由你决定。
- 自动玩：让本地 AI 继续，手动操作或暂停即可接管。
- 撤销 / 重做：回退或恢复操作；撤销后走新路线会清除旧的重做分支。
- 复盘：查看最近一百次操作，或对照重生挑战的路线。
- 设置：明暗外观、声音、减少动态效果、导出和导入进度。

打开菜单、离开页面或手动接管会暂停自动玩。AI 在本机浏览器计算，不保证每盘达到某个分数或数字。

## 保存与换设备

游戏自动把进度保存在当前浏览器。设置 → 导出进度，可把 JSON 存到「文件」或其他备份位置。另一台设备打开 **Touch 网页版**后，在设置中导入；导入前先导出目标端的旧进度，因为导入会替换它。

不同设备、浏览器和主屏幕环境不自动同步。清理网站数据或使用隐私浏览可能影响进度，请定期导出。网页版存档与桌面版、原生 App 格式不同，不能混用。

## 常见问题

**离线打不开？** 先联网完整加载，等待离线准备，再测试主屏幕入口。首次访问或缓存不完整时需要网络。

**更新后还是旧界面？** 先导出进度，再联网重新打开页面等待更新，不要先清空网站数据。

**滑动没反应？** 从棋盘内部开始滑动，或使用方向按钮。确认没有打开对话框。

**换浏览器找不到进度？** 各浏览器分别保存；使用原浏览器导出，再到新浏览器导入。

## 从源码运行（开发者）

需要 Python 3 与 Node.js 20 或更新版本，无需安装前端依赖。在源码目录执行：

```sh
python3 serve.py
node --test tests/*.test.js
```

开发地址为 `http://127.0.0.1:5184/`。`dist/` 是网页发布文件。手机正式使用需要 HTTPS；本地开发默认不注册离线缓存服务。

规则与浏览器布局已有测试，实体 iPhone / iPad 的触摸、系统手势、后台回收和主屏幕离线冷启动仍需设备验收。
