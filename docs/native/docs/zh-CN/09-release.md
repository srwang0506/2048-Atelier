# 版本、验证范围与文档维护

## 版本标识

游戏：1.0.1 Native，构建号 2。存档结构版本：1。文档修订：2026-09-29。本套说明以当前 Swift 原生代码为准，覆盖六种模式；旧桌面 / PWA 手册不能替代此处的规则和存档说明。

## 1.0.1 已修复的主要问题

- 模式菜单、确认弹窗或后台期间，排队输入仍可能继续执行。
- 连续操作不断推迟写入，主存档缺失时没有尝试备用存档。
- 损坏原文件可能被覆盖；混合模式状态、非法每日日期与不一致残局可被接受。
- 冲刺末步搜索了不存在的后续机会。
- 复盘切换长短路线时旧游标可能越界。
- 关卡动画期间选择奖励可能残留旧操作。
- 键盘焦点与后台保存分支已调整，仍需 iOS SDK / 真机验证。

详细触发条件见根目录 [BUGFIXES-1.0.1.md](../../BUGFIXES-1.0.1.md)。

## 文档媒体的性质

九段演示由实际原生 GameModel 与 SwiftUI 界面在 macOS 上运行，采样画面后组装为视频，再转换 GIF。是教学录制，不是 iPhone / iPad 屏幕录屏、触摸验证或帧率测试。底部英文条是录制工具的动作标注，不属于 App 界面。预先准备的中盘状态来自同一引擎实际操作；没有人工编造分数或改规则。具体方法、种子和生成脚本见[媒体说明](../media/README.md)。

## 仍未交付或验证

没有签名 IPA、App Store / TestFlight 上架，没有已完成的 iOS SDK 构建。真机动画、系统文件面板、后台挂起、外接键盘、VoiceOver、触感和旋转仍需验证。App 界面目前仅中文；三语文档不等于界面已完成三语本地化。没有自动 iCloud、联机对战和云排行榜。

## 文档约定

中文按钮名是定位控件的依据，英文 / 日文译名用于解释。箭头统一为棋盘移动方向：← 左、↑ 上、→ 右、↓ 下。示例棋盘中的 0 或点代表空格，真实方块没有 0。攻略中的路线必须从对应关卡重新开始执行。

离线阅读打开 `docs/index.html`，可切语言、跳章节、搜索和播放动图；Markdown 是可编辑来源。打印或另存 PDF 是静态阅读方式，GIF 在纸面 / PDF 不会播放，请保留 HTML 与媒体文件一起分发。
