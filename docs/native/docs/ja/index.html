はじめに・操作ガイド

対象：LUMINA Native 1.0.1、iPhone / iPad 用プロジェクト。更新日：2026-09-29。現在のアプリ画面は中国語です。 本書では日本語の説明に中国語のボタン名を併記します。日本語の説明書があることと、アプリの日本語表示に対応していることは別です。アプリ内の言語切り替えは未実装です。

最初の一局

  1. ソースコードを受け取った場合は、先にインストールとビルドを確認してください。ソース ZIP を iPhone に直接インストールすることはできません。署名済み IPA や TestFlight 招待は今回の配布物に含まれません。
  2. 起動すると「经典 2048」（クラシック）が開きます。保存済みのクラシックがあればその続きを表示します。他のモードの進行状況も残りますが、前回遊んだ別モードが起動時に自動で開くわけではありません。
  3. 盤面の内側を上下左右にスワイプします。一つのタイルをつかんで動かすのではなく、盤面全体をその方向へ動かします。
  4. 同じ数字がぶつかると合体します。スコアと手数の変化を確認しましょう。
  5. 上部のモード名と下向き矢印を押すと、六つのモードを選べます。クラシックが先頭です。
  6. アプリから離れると保存が要求されます。機種変更やアンインストールの前には、手動バックアップも書き出してください。

タッチ操作とキーボード

盤面内をはっきり上下左右にスワイプします。斜めの場合は移動量の大きい軸が採用され、短すぎる動きは無視されることがあります。外付けキーボードは矢印キーと A＝左、W＝上、D＝右、S＝下 に対応します。その他のショートカットは未実装です。Cmd+Z で戻せるとは限りません。

アニメーション中に待機させられるスワイプは最大二つです。非常に速い連続入力を無制限に蓄積することはありません。正確に操作したいときは、一手が落ち着いてから次を入力します。

シート、警告、再開始の確認が開いたときやバックグラウンドに移ったときは、待機中の入力を破棄して AI を停止します。戻った後は手動で動かすか、再度「自动玩」を押してください。

遠征の交換は「交换」を押し、数字が異なる二枚のタイルを順に選びます。最初に選んだタイルをもう一度押すと選択解除。「取消」で交換モードを終了します。

戻す・やり直す・最初から

**一手戻す（撤销一步）**は、盤面、乱数状態、スコア、手数、遠征状態を復元します。同じ操作を再び行えば同じ出現結果になります。戻す操作で都合のよい乱数を引き直すことはできません。凝時と交換も各一件の履歴を作ります。

**やり直す（重做一步）**は三点メニュー内です。戻した後に新しい有効な操作をすると、以前のやり直し分岐は消えます。遠征で最初の能力やステージ間報酬を選ぶと履歴が消えるため、前ステージに戻って報酬を選び直すことはできません。

**最初から（重新开始）**には確認があります。現在のモードの進行中の局だけを置き換えます。クラシック、スプリント、遠征は新しいランダム開始、パズルとレスキューは同じ問題の開始状態、デイリーは現在開いている日付の開始状態に戻ります。最高記録と取得済みの星は残ります。昨日のデイリーを開いている場合、今日を始めるにはモード一覧から「每日同局」を選び直します。

iPhone と iPad の配置

狭い画面ではタイトル、スコア、盤面、操作、説明を縦に並べます。横幅がある場合は盤面が左、情報が右です。高さの少ない横画面では情報欄をスクロールできます。iPad は利用可能な幅に合わせて配置しますが、二つの独立した局を同時表示する機能ではありません。回転や Split View の移行は実機での確認が必要です。

アクセシビリティ

盤面の各マスには行、列、数字または空白の読み上げラベルがあり、盤面に四方向のアクセシビリティ操作を用意しています。交換対象も選択可能です。現状の読み上げは中国語です。必要に応じて動きを減らす設定を使ってください。VoiceOver の一連の操作、大きな文字サイズ、キーボードのフォーカスは iOS 実機で未検証です。問題は報告用テンプレートに沿って記録してください。

共通の盤面ルール

盤面は 4 × 4 の 16 マスです。一方向に動かすと全タイルがその端へ滑り、隣り合う同じ数字が二枚ずつ合体します。その操作中に合体してできたタイルは、同じ一手の中で再び合体しません。

以下は一行を左へ動かした例です。新しいタイルの出現前を示します。0 は空白です。

移動前 左移動後 基礎得点
2 · 2 · 0 · 0 4 · 0 · 0 · 0 4
2 · 2 · 2 · 0 4 · 2 · 0 · 0 4
2 · 2 · 4 · 0 4 · 4 · 0 · 0 4。この一手で 8 にはならない
2 · 2 · 2 · 2 4 · 4 · 0 · 0 8
4 · 4 · 8 · 8 8 · 16 · 0 · 0 24
2 · 4 · 8 · 16 変化なし 0。盤面全体も変わらなければ無効な移動

盤面が変化すれば有効な移動です。手数を一つ消費し、通常は空いているマスに新タイルが出現します。標準では 2 が 90%、4 が 10%。遠征の能力はこの確率を変えたり、出現を抑えたりできます。合体せず位置だけ動いた場合も一手を使い、新タイルが出ますが、得点は 0 です。盤面が変わらない入力では、手数も乱数状態も進まず、新タイルも出ません。

基礎得点は合体後の数値の合計です。遠征ではさらに能力の補正を加えます。最高の一枚と総得点は別の指標です。盤面が埋まり、縦横に同じ数字が隣接していなければ、通常の移動はできません。遠征では使える能動能力も確認します。

クラシック

最初は二枚のタイルです。2048 を作っても強制終了せず、4096 やさらに大きな数字を目指せます。終了後は一手戻して別の選択を試せます。実際に動けなくなった局は、条件を満たせばレスキュー問題の抽出に使えます。

練習では最大タイルを一つの角に置き、近くの数字を大きい順に並べ、空きを残すことを意識すると考えやすくなります。移動前に最大タイルが角から離れないか確認しましょう。これは戦略の例であり、強制ルールや必勝法ではありません。

デイリー

端末のローカル日付を YYYY-MM-DD で表し、それに対応する固定シードを使います。同じ日付、同じルール、同じ操作列なら同じ盤面になります。違うルートでは空きマスが変わるため、出現位置も変わり得ます。オフラインの共通開始モードであり、世界ランキング、サーバー同期の締め切り、統一タイムゾーンはありません。

昨日の局を開いたまま日付が変わっても、自動で消えません。今日の局はモード一覧から「每日同局」を選んで開きます。昨日の画面で最初からを選ぶと昨日の開始状態に戻ります。保存済みの日付のうち最近七日分を保持します。手動 / アシスト最高記録はデイリーモード全体の記録で、日付ごとの別ランキングではありません。

60 手スプリント

数えるのは有効な方向移動だけです。60 秒の制限ではないので、考える時間は自由です。第 60 手で終了し、それ以前に動けなくなれば早期終了します。一手戻すと残り手数も戻りますが、過去の最高得点は下がりません。

最終手では第 61 手の配置を考えても得点にならず、その場での合体得点が重要です。AI もこの制限を考慮します。まだ手数がある間は、現在の点数と次の機会を両立させましょう。60 手に達しただけで盤面はまだ動ける場合、レスキュー抽出の「実際に動けない局」という条件は満たしません。

レスキュー

目標は 2048 ではなく、空きマスを確保することです。判定は移動・合体・新タイル出現の後に行います。合体直後に空きが三つあっても、新タイルで二つになれば三マス目標は未達です。

内蔵練習は「一线生机」（一筋の望み）、「腾挪之间」（動かす余地）、「逆转时刻」（逆転の時）の三問で、いずれも六手以内に三マスを空けます。「その他 → 残局档案」から選びます。戻す、再挑戦、ヒント、自動解答も使えます。

自分の局から問題を作る手順：

  1. クラシック、デイリー、スプリントで盤面が実際に移動不能になるまで遊ぶ。
  2. 結果欄の「寻找这局的另一种结局」（別の結末を探す）を押す。
  3. 最後の十手にある、空きが一マス以下の候補を調べる。六手以内に三マスを空ける検証済みルートを探す。
  4. 見つかったら「试着改写这局」（この局を書き換えてみる）で独立した問題へ進む。元のモードの局は残る。
  5. 見つからなかった場合、その範囲と時間で条件を満たす転機を確認できなかったという意味で、もっと前の全局面が救えなかった証明ではない。

個人アーカイブは最大六件です。追加時には現在の問題に必要でない古いものから整理します。内蔵練習は六件枠を消費しません。二ルートのリプレイはレスキュー専用で、すべてのクラシック長局の動画を再生する機能ではありません。

「对照复盘」（比較リプレイ）では「原来的路线」（元のルート）と「转机路线」（救済ルート）を切り替え、「上一步 / 下一步」で進めます。切り替えると手順 0 に戻ります。クリア前にリプレイを開いた時点でアシスト扱いです。元のルートを見るつもりでも、最初に解答ルートが表示されるためです。クリア後の閲覧では、そのクリア済み局の区分は変わりません。

能力遠征：ステージ・エネルギー・全九能力

一回の遠征の流れ

最初に「连击引擎」（コンボエンジン）、「蓄能核心」（蓄電コア）、「豪赌协议」（ギャンビット）の三つから一つを選びます。各ステージは制限手数内に、そのステージの目標点を稼ぐ形式です。上部スコアは累計、進捗バーは現在スコアからステージ開始時のスコアを引いた値です。

ステージ 中国語名 / 日本語名 今回の目標点 基本手数 余裕のリズム I / II
1 启程 / 出発 100 26 30 / 34
2 蓄势 / 力を蓄えて 260 34 38 / 42
3 回响 / 響き 520 42 46 / 50

最初の五ステージでは達成後に停止し、三択の報酬が出ます。新しい能力か、所有能力の II への強化を選びます。上限に達した能力は候補に出ません。盤面、累計点、能力、エネルギーは持ち越します。二枚以上のタイルがあれば最小値を一枚取り除いて空きを作ります。同値なら左上から行順に見て最初の一枚です。

余った手数や、目標を超えた分の得点は次ステージの進捗に繰り越しません。報酬選択時にコンボ、凝時の残り回数、クールダウン、戻す / やり直す履歴がリセットされます。第六ステージ達成で遠征クリアです。最後の一手で目標に届けばクリアを優先し、届かなければ手数切れ、または移動も能力使用もできないと失敗です。

エネルギーと能動能力

一組合体するごとに基本 1 エネルギーを得て、最大 12 まで保持します。蓄電コアで一組あたりの獲得量が増えます。合体しない移動では増えません。エネルギーは遠征だけの要素です。

能力 基本消費 操作 効果
凝时 / 凝時 5 「凝时 · 5」を押す 次の有効な移動二回で新タイル出現を止め、六手のクールダウンを設定
交换 / 交換 6 交換を押し、値の異なる二枚を選ぶ 二枚の位置を入れ替える。合体や新タイル出現はしない

どちらも移動手数を使わず、直接の得点はありませんが、戻せる操作履歴を一件作ります。空白や同じ数字同士は交換できません。凝時には必要エネルギー、クールダウン 0、凝時中でないこと、盤面が移動可能であることが必要です。完全に詰まった盤面を凝時だけで救うことはできませんが、交換なら救える場合があります。

凝時回数とクールダウンは有効な方向移動でのみ減ります。待つ、無効スワイプ、交換では進みません。凝時中に空間還流も発動した場合、その手でも凝時を一回消費します。ステージ移行で凝時とクールダウンはリセットされます。

凝时晶体 / 凝時クリスタル 凝時が三回の有効移動に持続 四回持続 クールダウンは六手のまま

コンボは一手の合体組数ではなく、「合体のある移動」が何手続いたかです。無効な入力は途切れさせず、合体しない有効移動は途切れさせます。能動能力はコンボを進めず、途切れさせもしません。

得点計算

基礎点を G、角の加点を C、共鳴の加点を E とすると：

一手の得点 = (G + C + E) × コンボ倍率 × ギャンビット倍率

最後に最も近い整数へ丸め、ちょうど .5 の場合は近い偶数を採用します。例えば基礎点 24、角で 8 を生成、二組以上合体し、角 I、共鳴 I、コンボ I の連続二手目、ギャンビット I がある場合は (24 + 4 + 12) × 1.25 × 2 = 100 点です。

コンボ I の一～五手目の倍率は 1、1.25、1.50、1.75、2。その後も 2 です。II は 1、1.40、1.80、2.20、2.60 で、その後も 2.60 です。

組み合わせの練習例

エネルギー重視：蓄電コアとワープレンズで交換の機会を増やします。12 を超える分は保持できないため、余裕のあるうちに有効な交換を考えます。

複数合体重視：共鳴回路と空間還流で一手二組以上を準備し、得点と空間を得ます。発動のためだけに安定した並びを崩さないことも大切です。

倍率重視：コンボエンジンとギャンビットで目標点へ早く近づけますが、4 の増加や連続合体の維持が難しくなります。無条件で有利になる組み合わせではありません。

報酬はその場の三択から選ぶため、理想の組み合わせが揃う保証はありません。AI はプレイ中の能力を使えますが、ステージ報酬はプレイヤーが選びます。遠征の操作例も参照してください。

AI アシスト・記録・セーブデータ

ヒントと自動プレイ

「提示」は提案を計算するだけで、勝手に動かしません。カードに方向や能力が表示され、「走这一步」で実行できます。自分の判断で別の手を入力しても構いません。「自动玩」は計算と操作を繰り返し、「暂停」で止まります。

手動スワイプ、戻す、やり直す、モード切り替え、設定、警告、バックグラウンド移行、ステージ能力選択で自動プレイは停止します。メニューを閉じても自動再開しないため、必要ならもう一度「自动玩」を押します。

ヒントを要求した時点でアシスト扱いになります。提案を無視しても同じです。自動プレイの開始、クリア前のレスキュー比較リプレイも該当します。AI を止める、操作を戻す、バックアップを出力して読み直す、といった方法では区分を戻せません。最初から新しく始めた局は再び未アシストです。

探索の仕組みと限界

モード 方法 提案の意味
クラシック・デイリー Expectimax による確率探索 移動と新タイル出現の分岐を比較。空き、合体候補、並び、最大タイルの角配置を評価
スプリント 残り手数で範囲を制限する確率探索 制限を超えた架空の手を評価せず、最終手は即時得点を比較
遠征 能力効果を含めた確率探索 得点・出現への効果を扱い、交換と凝時は追加のヒューリスティックで選ぶ。全構築の完全最適化ではない
パズル・レスキュー 乱数状態を含む幅優先探索 短いルートから調べ、発見時には再現可能な最短解を返す。時間制限あり

通常探索では行パターンの事前計算、同じ状態のキャッシュ、段階的な深さの拡張、非常に低い確率分岐の打ち切りを使います。「优先 / 备选」は推奨順の意味で、勝率や保証得点ではありません。通常のランダムモードで未来の乱数列を先読みする方式ではありません。固定問題のパズルとレスキューでは、再現可能な解を得るために確定した乱数状態を使います。

「灵敏」の通常予算は約 0.14 秒、「深度思考」は約 0.55 秒です。これは探索予算で、一手全体の時間保証ではありません。パズルとレスキューには少なくとも約 1 秒を割り当てます。深い探索は電力や発熱を増やし得ますが、常に最適な手を選ぶ保証はありません。「探索未完了」と「許可範囲を調べ尽くしても解なし」は異なります。状況に応じて再試行や一手戻すを使ってください。

AI から学ぶ

クラシックでまずヒントを見て、自分の候補と比較してから実行してみましょう。ゆっくりした自動プレイなら空きを残す手順を観察しやすくなります。遠征は報酬選択で止まるため、報酬を選んでから自動プレイを再開します。手動最高記録を狙うときは最初からアシストを使わないでください。

ホスト環境での記録として、クラシックは 3,200 手、69,592 点、最大 4096（1.0 の保存済み結果）、遠征は 1.0.1 で六ステージ、138 操作、6,422 点を確認しています。特定シードでの一例であり、実機性能、平均勝率、到達点の保証ではありません。

最高記録と星

各モードに手動とアシストの最高点があります。デイリーはモード全体の記録で、日別ランキングではありません。戻すと現在点は下がっても、過去最高は下がりません。星は問題ごとの最高値を保持し、後で星一つでも既存の星三つは消えません。オンライン順位、アカウント統合、友達対戦、サーバー戦績はありません。

自動保存に含まれるもの

進行中の局、盤面と乱数状態、スコア、手数、アシスト区分、戻す / やり直す履歴、遠征能力、パズル最高星数、個人レスキュー、記録と設定を保存します。デイリー以外は一モードにつき進行中一局、デイリーは最近七つの日付、個人レスキューは六件です。

通常の変更は約 280 ミリ秒後に始まる書き込みへまとめ、連続操作でも無期限に延期しません。バックグラウンド移行時には即時書き込みを要求します。ただし突然の強制終了、空き容量不足、端末異常は直近の保存に影響し得るため、重要な進行状況は別途出力してください。

書き込みはアトミックに行い、直前の読める保存を予備として残します。主ファイルが消失・破損していれば予備を試し、読めない元ファイルは置き換える前に別名保存します。

バックアップの書き出し

  1. 右上の設定を開く。
  2. 「进度」の「导出进度备份」を押す。
  3. システムのファイル画面で保存先を選ぶ。標準名は LUMINA-2026-09-29.json のような形式。
  4. 「ファイル」で実際に保存されたことを確認してから、アンインストールや機種変更を行う。
  5. 同日に何度も保存するときは端末名や時刻を加え、唯一のコピーを上書きしないようにする。

出力は現在の一局だけでなく、全モード、記録、設定を含む完全バックアップです。iCloud Drive にファイルを置く、AirDrop で送る、という操作は手動転送であり、アプリの自動 iCloud 同期ではありません。

読み込みと機種変更

移行先に動作するネイティブアプリを用意し、設定 →「导入进度备份」で JSON を選びます。サイズ、構造、盤面、乱数、問題を検査してから「用备份替换本机进度？」と確認します。承認すると全モードの進行状況、最高記録、設定を置き換えます。二台分の統合はしません。先に移行先の現状も書き出してください。

完了後はまずクラシックが表示されます。他のモードは一覧から開きます。不正なファイルや 24,000,000 バイトを超えるファイルは拒否します。ネイティブ版 JSON は Python デスクトップ、Windows、PWA の保存形式と互換ではありません。拡張子を JSON に変えても変換されません。

データとプライバシーの範囲

ゲームと AI は端末内で実行し、サーバー接続、ログイン、広告 SDK は不要です。保存場所はアプリのサンドボックス内 Application Support/Lumina です。通常は内部ファイルを編集せず、設定の入出力を使ってください。バックアップにはゲーム状態と設定が入り、開発者の署名アカウントは入りません。ただし共有すれば戦績や途中盤面も相手に渡るため、共有先は自分で選んでください。

よくある質問・不具合の報告

動かない、押しても反応しない

メニュー、警告、報酬選択、終了状態になっていないか確認してください。移動で盤面が変わる方向だけが有効です。盤面の中から十分な距離をスワイプします。動作中の待機入力は最大二つで、それ以上を蓄積しません。狭い画面の電球はヒントです。

「准备棋盘…」のままの場合は、内蔵問題の読み込みエラーがないか記録し、閉じて開き直します。開発者はリソースの同梱を確認してください。未バックアップの進行状況を、調査のためだけにアンインストールしないでください。

2048 を作っても終わらない

クラシックとデイリーはそれ以上を目指せます。パズルは指定数字、スプリントは手数、遠征はステージ得点で判定します。終了条件はモード別です。

合体したのにレスキューが成功しない

通常は合体の後に新タイルが一枚出ます。レスキューはその後の空き数を数えるので、合体直後に三つあっても二つに戻る場合があります。新タイルを抑える凝時と空間還流は遠征だけです。

いつの間にかアシスト扱いになった

ヒント要求、自動プレイ、クリア前のレスキュー比較リプレイでアシスト扱いになります。提案を採用しなくても同じです。戻すやバックアップ読み込みでは消えません。以前の手動最高点は残りますが、この局のその後の点数はアシスト区分へ記録されます。

星三つにならない

標準手数以内、アシストなし、戻す未使用の全条件が必要です。標準手数と最大手数を混同しないでください。戻すを使えば未アシストでも最大二つ、アシスト後のクリアは一つです。新しく挑戦するにはその問題を最初から始めます。

AI が止まる、AI でも負ける

報酬、終了、メニュー、手動介入で止まります。メニューを閉じた後は再度自動プレイを押してください。有限時間の探索と評価なので、ランダムな局で無限に生き残る保証はありません。深い思考は探索予算を増やすもので、完全最適解の証明ではありません。遠征の報酬は自分で選びます。

遠征の能力が灰色になる

凝時は 5 エネルギー、冷却なし、凝時中でないこと、移動できる盤面が必要です。交換は必要エネルギーと異なる数字の二枚が必要です。アニメーション中は能力操作を待ちます。エネルギー上限は 12。六手のクールダウンは六秒ではなく、有効移動六回です。

友達とデイリー盤面が違う

端末のローカル日付、モード、バージョン、すでに動かした手を確認してください。タイムゾーンによって日付も違います。同じ盤面には同じ操作列が必要で、通信で同期する機能ではありません。昨日の局を開いたままなら、デイリーを選び直して今日の局を開きます。

バックアップを読めない、古い状態に戻った

状況 確認・対処
存档格式不正确（形式不正） このネイティブ版から出した、欠けていない未改変の JSON か確認。デスクトップ等とは非互換
超过 24 MB（大きすぎる） 上限 24,000,000 バイト。元を残し、適当な項目を消して縮めない
已从备用存档恢复（予備から復元） 主ファイルが消失・破損。直近操作のない旧版かもしれないので、新しい手動バックアップがあれば利用
読み込むとクラシックが開く 現在の仕様。他のモードを選んで続きへ
二台それぞれで進んだ 自動統合はしない。両方を先に出力し、どちらを残すか決める
保存失败（保存失敗） 空き容量を確認し、可能なら出力、エラー全文を記録

保存不調の調査中に何度も最初から始め、唯一の利用可能な状態を上書きしないでください。

音・触覚・動きが想定と違う

アプリ設定、システム音量、消音、出力先を確認します。実装は他の音と混合できる環境音のカテゴリを使用します。触覚はハードウェア依存で、一部 iPad は同じ振動を出せません。動きを減らす設定はアプリとシステムの両方を確認してください。説明用 GIF はフレームを採取した教材であり、iPhone の実際の更新頻度を評価する材料ではありません。消音、触覚、フレームレートは実機検証待ちです。

iPhone / iPad にどう入れるのか

ソース ZIP、Xcode プロジェクト、macOS プレビューはインストール可能な IPA ではありません。完全な Xcode、対応 SDK、署名設定が必要です。現状 TestFlight 招待はありません。導入手順を参照してください。

英語・日本語画面、Windows、通信対戦はあるか

本書は三言語ですが、現在のアプリ表示は中国語で、言語切り替えボタンはありません。以前の Python デスクトップ、Windows、PWA 版は独立して残っています。本書はそれらを iOS アプリとして扱わず、保存形式や全機能の一致も保証しません。ネイティブ版には通信対戦、クラウドランキング、自動クラウド同期はありません。

インストール・ビルド・開発者向け説明

配布物の状態

LUMINA 1.0.1 は Swift / SwiftUI 製の iPhone・iPad 共通ネイティブアプリのプロジェクトです。最低対応として設定した OS は iOS / iPadOS 16.4。WebView は使いません。コア、リソース、Xcode プロジェクト、テスト、説明書、教材動画を含みます。現状は署名済み IPA、シミュレータービルド、TestFlight、App Store 公開のいずれもありません。

最低 OS とコンパイラーの要件は別です。パッケージは Swift 6.0 以上のツールチェーンを要求し、Swift 5 言語モードを使います。端末の OS に対応する Xcode も必要です。この開発 Mac は Command Line Tools のみで、macOS ホスト環境の検査は済んでいますが、iOS SDK ビルドと実機受け入れ試験は未実施です。

自分の端末で起動する

  1. Mac に完全な Xcode を入れます。Mac と端末 OS の組み合わせは Apple の Xcode 対応表で確認してください。xcode-select --install のコマンドラインツールだけでは足りません。
  2. Xcode を起動し、必要な追加コンポーネントを入れます。Settings → Locations → Command Line Tools でその Xcode を選びます。
  3. ソースを書き込み可能なローカルフォルダーへ展開し、Lumina.xcodeproj を開きます。共有 Scheme は Lumina です。
  4. Xcode → Settings → Accounts に自分の Apple Account を追加。ターゲットの Signing & Capabilities で Team を選び、必要なら Bundle Identifier を自分用の一意なものへ変更します。
  5. 端末を接続してロック解除し、信頼のペアリングを完了。Xcode・OS の案内に従って Developer Mode を有効にし、実行先にその iPhone / iPad を選びます。
  6. ▶ Run を押し、初回ビルドと署名を待ちます。失敗時は最初の具体的なエラーを読みます。拡張子を変えても署名問題は直りません。
  7. 起動後にクラシック移動、縦横切り替え、全モード、保存、音と触覚、入出力を確認します。

公式資料：実機・シミュレーターでの実行、アカウントとチーム。資格や配布条件は利用時点の Apple の規定に従います。個人端末で Run することと TestFlight 配布は別です。

一つ目は Mac 上の Swift Testing、二つ目は設定・リソース参照検査です。三つ目は iOS Simulator ビルドも試み、SDK がなければ明確に失敗します。ホスト環境テストは iOS ビルドの代わりにはなりません。

保守上の注意

App/*.swift を増やしたら python3 tools/generate-project.py で参照を更新できます。生成器は Team / Bundle Identifier を初期値へ戻すため、ローカルの署名設定を先に控えてください。文書収録テストは環境変数で有効にした場合だけ動き、独立した一時保存先を使います。プレイヤーの通常データには触れません。

教材動画について

九本の教材は本物の GameModel と SwiftUI を macOS 上で実行し、画面を採取して動画にまとめ、その動画から GIF に変換しています。iPhone / iPad の画面録画、タッチ検査、フレームレート測定ではありません。下の英語帯は収録側の注釈で、アプリ画面の一部ではありません。途中から始まる例も同じエンジンで実際に操作した状態を使い、得点の捏造やルール変更はしていません。種と再生成方法はメディア説明に記載しています。

まだ完了していないもの

署名 IPA、App Store / TestFlight 公開、iOS SDK ビルドは未完了です。実機アニメーション、システムファイル画面、サスペンド中の保存、キーボード、VoiceOver、触覚、回転は確認が必要です。アプリ表示は現在中国語のみで、三言語の説明書は UI の翻訳完了を意味しません。自動 iCloud 同期、対戦、クラウド順位はありません。

読み方と更新

中国語のボタン名で操作場所を特定し、翻訳名で意味を説明します。← 左、↑ 上、→ 右、↓ 下は盤面を動かす方向です。例の 0 や点は空白で、0 のタイルは存在しません。解答ルートは対応する問題を最初から始めて入力してください。

docs/index.html を開くと、オフラインで言語選択、目次、検索、GIF アニメーションの再生を利用できます。編集元は Markdown です。印刷や PDF 保存は静的になり、GIF は動きません。動きが必要な配布では HTML とメディアをまとめて渡してください。
