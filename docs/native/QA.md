用实际 SwiftUI 视图在 macOS ImageRenderer 下检查了 390 × 763、335 × 620、1194 × 790、750 × 350 四种内容区域。修复了小宽度下的控制项挤压、文字基色解析，以及方块内部文字重复投影。

## 构建环境限制

此 Mac：macOS 15.3，Apple Silicon，Swift 6.1.2，只有 Command Line Tools / macOS SDK；`xcrun simctl` 和 iOS SDK 不可用；有效签名身份为 0。

Command Line Tools 目录还混有 2024 年旧 PackageDescription 私有接口和重复 SwiftBridging module map。为了运行已有 macOS 工具链检查，本次使用 `/private/tmp/lumina-toolchain` 中的 Swift 编译器包装器和 VFS overlay：PackageDescription 私有接口映射至该工具链自带的新版公开接口，旧重复 module map 映射为空文件。系统安装没有被修改。模块缓存、SwiftPM 配置和构建输出也放在临时目录。

这套临时处理仅使 macOS 上的源码检查可执行，不能补出 iOS SDK。`tools/archive.sh` 已实际运行，并按预期以退出码 2 报告缺少完整 Xcode / iOS SDK。**当前没有 `.ipa`、已签名 iOS `.app`、模拟器构建或 App Store / TestFlight 发布。**

下一步必须在完整 Xcode 中完成 iOS SDK 构建，再选择 Apple Team、连接目标设备完成真机验收。账号、证书、Team ID、设备 UDID 都没有写入源码包。
