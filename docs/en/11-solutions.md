# Twelve puzzles and three Rescue solutions

The resources, starting boards and routes for these twelve puzzles and three practices have been checked against Desktop v12. Use each edition’s control chapter for its button locations.

Try each challenge yourself before reading. Every route starts at its original board: restart the matching challenge first. Arrows are move directions; 0 is empty. Routes are generated directly from bundled game resources so translation cannot alter a direction.

Reading an external manual is outside the app, so it cannot automatically mark that you consulted these solutions. For your own unassisted challenge, avoid external answers; a practiced known route is different from solving a puzzle blind.
