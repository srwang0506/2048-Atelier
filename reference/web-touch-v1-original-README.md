# LUMINA 2048 · 触屏版

为 iPhone 和 iPad 单独设计的 Safari / PWA 版本。电脑版 Python 游戏保留不变。

## 游玩与安装

用 Safari 打开部署后的 HTTPS 链接，点「分享 → 添加到主屏幕」。首次完整加载并完成离线准备后，可以离线游玩。推荐 iOS / iPadOS 16.4 或更新版本。

这是网页应用，不是 App Store 应用或可侧载的 IPA。当前发布为私人试玩，需要用所属账号登录。游戏本身不要求额外注册。

## 六种玩法

- 经典 2048：默认进入，经典在模式选择中排第一；合成 2048 后仍可继续。
- 能力远征：六关、九种两级能力，凝时与交换，逐关选择构筑。
- 败局重生：从真实败局最近十步中寻找可验证的转机；附三道练习和三种路线复盘。
- 每日同局：按设备本地日期生成，七天独立存档。
- 谜题剧场：保留电脑版全部十二道谜题、最短解和星级规则。
- 六十步冲刺：六十次有效移动，撤销会恢复步数。

支持触屏滑动、方向按钮、键盘方向键 / WASD、撤销 / 重做、最近一百次操作复盘、提示、自动玩、明暗主题、声音和减少动态效果。后台、菜单打开或手动接管时暂停自动玩。

## 存档

六种玩法分别保存在浏览器 IndexedDB，带上一份备份和离开页面时的应急快照。设置中可导出 JSON，在另一台设备导入。导入会替换该设备当前触屏版进度。

不同设备、浏览器、主屏幕应用及电脑版分别保存，不自动云同步。隐私浏览、清理网站数据或系统回收网站存储可能清除进度；重要存档请导出到「文件」。

## 算法与兼容

规则引擎与显示分离。整数种子的 MT19937、随机落子顺序、每日种子、十二道谜题和三份练习与 Python 版对照验证。远征能力效果一致，远征选卡顺序使用触屏版自己的确定性洗牌。

AI 在独立 Web Worker 中进行迭代加深 Expectimax，使用行查表、状态缓存与低概率分支截断。保留最后完整完成的搜索深度；大数字不会在 16 位行编码中溢出。能力远征搜索考虑已获得的能力、能量、凝时、交换及新方块概率。谜题与重生挑战使用携带完整随机状态的广度优先搜索，并通过正式规则重放验证路线。超时不宣称无解。

单次开发机试跑：45 ms 搜索预算下连续 3,000 步，66,828 分，最大 4096，结束测试时仍可继续；六关远征另一次试跑全部完成、6,390 分。它们是具体试跑结果，不是手机性能或胜率保证。

## 本地开发

不需要安装前端依赖。需要 Python 3 和 Node.js 20 或更新版本。

```sh
python3 serve.py
node --test tests/*.test.js
```

本机浏览器访问 `http://127.0.0.1:5184/`。手机正式使用需要 HTTPS；局域网 HTTP 地址不能保证 Web Crypto / 离线安装可用。本地开发默认不注册 Service Worker，避免旧缓存掩盖修改。

`dist/` 包含网页版的完整部署文件。游戏没有外部运行时依赖，也不会把存档上传给网站。站点提供三个可选 WebMCP 工具：读取棋盘、移动一次、打开玩法选择；浏览器不支持时自动略过。

## 验证范围

自动检查覆盖规则对照、全部谜题、全部练习、真实败局提取、宽数字、无效移动、辅助标记、能力撤销、末步通关、存档校验、每日记录裁剪、离线资源完整性与拒绝缓存登录重定向。浏览器验证包含响应式布局、模式切换、AI、复盘及存档。

未完成实体 iPhone / iPad 的触摸、系统返回手势、后台进程回收、主屏幕离线冷启动和帧率测量；尚无原生 iOS 安装包。
