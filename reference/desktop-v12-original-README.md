# 2048 · 第十二版

Python 桌面游戏。第十二版修复跨平台资源读取、备份恢复和截图错误处理，加入重复启动保护，提供自带运行环境的 Windows 64 位便携包。经典玩法仍放在首位；六种玩法、AI、撤销重做与独立进度全部保留。

## 启动

macOS 双击 **启动游戏.command**。本机独立 Python 环境已经安装，游戏位于 `/Volumes/sirui/2048-Atelier`。新版继续读取原来的进度与战绩。

```sh
cd /Volumes/sirui/2048-Atelier
.venv/bin/python game.py
```

源码运行环境使用 Python 3.12–3.14 的 64 位版本。macOS 首次安装：`python3 -m venv .venv`，再运行 `.venv/bin/python -m pip install -r requirements.txt`。

### Windows 便携版

下载 `2048-v12-Windows-x64.zip`，**完整解压后双击 `2048.exe`**。包内附带 Python 3.13.15、所有游戏依赖和中文字体；不需要自行安装 Python，启动和游玩不需要联网。适用于 Windows 10 / 11 的 Intel、AMD 64 位电脑。`runtime/` 和 `fonts/` 必须与入口一起保留。

Windows 存档位于 `%LOCALAPPDATA%\2048-Atelier\data\save.json`，截图位于同一应用目录的 `exports/`，启动异常日志在 `logs/latest.log`。首次运行会保留已有用户目录进度；用户目录尚无存档时，才从旧版游戏目录的 `data/save.json` / `save.bak` 复制迁移，原文件不删除。

双击 `check-windows.bat` 可检查依赖、字体、12 个章节、3 个练习残局、临时存档与后台 AI；结果写入 `logs/diagnostics.json`，不改个人对局。`启动游戏.bat` 提供控制台入口，便于查看错误。

如果使用源码包，先安装兼容的 Python，再双击 `启动游戏.bat`。它会在首次运行时联网准备独立环境，已就绪时直接启动；检测到失败会停下显示原因。重复打开会提示返回现有窗口，避免两个游戏进程同时覆盖存档。

**此轮没有 Windows 实机环境。** 已做依赖哈希、64 位 PE 导入检查、缺失运行库修复、跨平台路径测试及字体回退渲染，但这些不代替 Windows 窗口、声音、显卡与帧率实测。详见 `Windows使用说明.txt` 与 `测试报告.md`。

## 字体与排版

macOS 优先读取系统安装的苹方：正文 Regular、操作 Medium、标题 Semibold；数字使用 Helvetica Neue Medium，标志使用 Bold。macOS 系统字体只在本机读取，不随源码分发。Windows 中文使用随包分发的 Noto Sans SC Regular、Medium、Bold，数字优先使用系统 Segoe UI；字体路径读取实际 Windows 目录，不假设安装在 C 盘。没有可用系统字体时使用 Noto 回退。开源字体许可证见 `fonts/OFL.txt`。本轮已用 Noto 回退渲染检查，尚未在 Windows / Linux 实机验证。

大厅默认显示排在前面的「经典与挑战」，经典模式占据左侧主卡；右侧的「精选玩法」收录两种新玩法。卡片使用统一间距和对齐。整张卡片可点击，悬停使用轻微描边与箭头反馈；棋盘上的复盘、教练、设置合为一个工具区。设置、章节、分析与复盘共用新的字体和光学基线。

## 六种玩法

### 模式大厅

启动后先选择玩法，右上角可直接继续当前局。对局内点击左上角的模式名称，或按 **B** 返回大厅。六种模式分别保存当前进度，切换不会覆盖经典对局。默认进入「经典与挑战」，经典玩法放在首位；点击后面的「精选玩法」进入两个新模式。

| 模式 | 核心玩法 |
|---|---|
| 能力远征 | 六关限步挑战，九种两级能力，合并充能后使用交换与凝时 |
| 绝境重生 | 从真实败局抽取已验证可恢复的残局，六步内腾出至少三个空格 |
| 经典 | 无限步数，合并出更大的数字，保留已有 AI、撤销、复盘等功能 |
| 解局剧场 | 12 个固定残局，在 3–6 步的限制内合成指定数字 |
| 60 步冲刺 | 以 60 次有效移动争取高分，无路可走时提前结束 |
| 每日同局 | 按日期固定开局与随机种子，独立保存进度 |

### 能力远征

从大厅选择「能力远征」→「开始远征」，在三张能力卡中选择一张。开局提供连击、蓄能、豪赌三种方向，每过一关再三选一，可获得新能力或将已有能力升至二级。共有九种能力；打开棋盘旁的「能力」可查看本局的实际效果。

| 关卡 | 本关需获得的分数 | 基础有效步数 |
|---|---:|---:|
| 启程 | 100 | 26 |
| 蓄势 | 260 | 34 |
| 回响 | 520 | 42 |
| 临界 | 900 | 46 |
| 跃迁 | 1,400 | 52 |
| 终章 | 2,200 | 60 |

目标按每关新增分数计算，总分持续累加。最后一步达到目标仍算过关。每次进入下一关会移除一枚最小方块，保留其余棋盘、能力与能量；连击和凝时状态归零，并从新关卡开始记录撤销历史。过关提供的三张卡已固定，关闭面板、切换模式或重启不会刷新选项。

每组合并获得一点能量，最多储存 12 点。两种主动能力从第一关就可使用：

- **交换**：基础消耗 6 点，选中任意两枚不同数字交换位置。折跃透镜可将消耗降至 4 / 3 点。
- **凝时**：消耗 5 点，接下来两次有效移动不落新方块，冷却六次有效移动。凝时晶体可延长至三次 / 四次。

主动能力不扣步数，也不会自行落子，可以撤销。棋盘无法滑动但仍有能量交换时，游戏会等待玩家使用能力。能量不足、冷却或无法使用时，按钮会说明原因。

| 能力 | 一级 → 二级 |
|---|---|
| 连击引擎 | 从连续第二次合并起，每次增加 25% → 40% 得分，最多四层；无合并移动会断连 |
| 蓄能核心 | 每组合并额外充能 1 → 2 点 |
| 豪赌协议 | 得分 ×2 → ×2.5；同时新方块为 4 的概率提高至 30% → 40% |
| 角落增幅 | 四角合并额外获得该方块 50% → 100% 分数 |
| 共鸣回路 | 一步合并至少两组时，额外增加基础分的 50% → 100% |
| 空间回流 | 一步合并至少 3 → 2 组时，本步不落新方块 |
| 从容节拍 | 每关增加 4 → 8 步，选择后立即生效 |
| 折跃透镜 | 交换消耗降至 4 → 3 点 |
| 凝时晶体 | 凝时阻止接下来 3 → 4 次落子 |

角落与共鸣先增加基础分，再计算连击与豪赌倍率，因此可以组合打法。远征单独保留至多 12 场较高成绩及使用的能力，分数不计入经典纪录。未完成的远征可随时继续，重新开局前会提示。

远征使用单独的限时 Expectimax，考虑当前能力、能量、凝时和实际落子概率，也会使用主动能力，并优先处理最后一步的过关目标。空位较多时对落点采样，以控制响应时间；它是启发式玩家，不保证最优。过关后自动玩暂停，由玩家选择能力。

### 绝境重生

经典、每日同局或冲刺因为棋盘无路可走而结束时，后台会检查最近最多十步，寻找只有零或一个空格、但仍能在六步内恢复空间的局面。冲刺单纯用完步数不会触发提取。找到后可从结束界面或大厅的「绝境重生」进入。

挑战的目标是：在六次有效移动内腾出至少三个空格，并保持棋盘可以继续移动。进入挑战不会覆盖原局；返回经典或相应模式仍能看到原来的棋盘。挑战从零分、零步开始，保留原位置的随机状态；重试同样的走法会得到同样的落子，改变走法可能改变落点。

- 通过广度优先搜索找到最短路线，并用真实游戏引擎重放验证后才生成挑战。
- 按每条分支恢复完整随机状态，保留原游戏「先选位置、再决定数值」的顺序。
- 可以撤销、原局重试、提示或自动玩。手动和含辅助的最佳步数分开记录。
- 「路线对照」并排展示本次走法 / 原来的败局与验证路线，可逐步回看。完成前查看参考解会标记辅助，撤销不会清除该标记。
- 最近六个个人残局保存在本机；当前正在玩的残局会保留。暂无个人残局时，提供三个明确标为「练习」的真实败局样本，最短解分别为 3、5、5 步。

并非每盘败局都能找到符合条件的挑战。搜索有时间上限；超时或没有找到只表示本次未发现，不证明局面无解。原局保存与操作不受影响。

### 解局剧场

每章的目标从 64 逐步提升到 2048。首批 12 章最短解为 2–5 步，每章允许比最短解多一步。棋盘右侧显示剩余步数及下一枚方块；原局重试会复现相同随机序列，改变方向后落点可能不同。

- 无辅助、无撤销，以最短步数完成：三星。
- 其余独立完成：二星；使用提示、教练或 AI 演示完成：一星。
- 通关星级保留最高记录；选择正在进行的同一章会继续进度，「原局重试」才会重开。
- 选择另一章会替换当前未完成章节，但已获星级保留。
- 设置 → AI 分析，可预览包含确定新方块的下一步、查看每个方向是否能在余下步数内解开，也可以展开完整解法。

这个模式使用独立的**广度优先最短路径求解器**，按照本关实际的固定落子规则搜索，没有用经典模式的概率评分冒充确定解法。只在解局剧场里，AI 能使用已固定的落子序列。经典、每日、冲刺仍使用原来的 Expectimax，不读取未来随机状态。

### 60 步冲刺

只扣除能移动棋盘的有效操作。第 60 步结算，也可在无路可走时提前结束；手动与含辅助的个人最佳分别记录。允许撤销，撤销会回退步数；辅助标记不随撤销清除。冲刺和解局的分数不会进入经典最高分或战绩表。

### 原有功能全部保留

- **自适应 AI**：设置里默认启用。空旷局面更快返回，拥挤局面分配更多思考时间；连续完整搜索深度得出相同方向时，可以提前结束。快速、标准、深入仍可选。
- **方向预览**：设置 → 查看 AI 分析。点击四个方向，比较合并后的棋盘、收益、落子后空格及下一次落子后的终局风险。预览不含随机新方块，也不会执行走棋。
- **教练**：右上角或按 C 开关。停下操作后自动在后台分析，显示推荐和局面说明，由玩家决定下一步。默认关闭。
- **每日同局**：从模式大厅进入。每天使用固定种子；相同日期和操作序列可以复现相同落子。每日重开会重试当前挑战日期；通过大厅可以进入今天的挑战。
- **复盘**：右上角或按 R。回看最近 100 步，支持逐步、播放、点击得分曲线定位；不会改动当前棋盘、随机状态或撤销记录。

每日挑战在本机运行，没有联网排名。提示、教练分析、AI 走一步和自动玩会将本局记为「含辅助」，撤销不会消除辅助标记。首次从旧版升级时，原「标准」档迁移到「自适应」；原快速、深入设置保留，之后尊重玩家选择。当前模式保存在主存档，另保留经典、解局、冲刺、远征、重生及最近七个已保存日期的每日对局；旧日期没有独立选择入口。

## 操作

- 方向键、WASD、鼠标拖动或触控滑动移动方块。
- 「撤销」「重做」支持最近 100 步，棋盘、得分与随机落子状态一起恢复；关闭后再次启动仍可继续撤销。升级前未保存的撤销历史无法补回。
- 「提示」计算当前局面的推荐方向，并显示这一方向能合并几组、直接得到多少分；细线标记合并后的位置。这些是当前一步的结果，不是胜率预测。
- 「自动玩」开始 AI 对局；空格暂停，方向键随时接管。
- 右上角圆形设置按钮可以调整 AI、速度、深浅外观、音效、动画、全屏，以及查看战绩和玩法。
- 进度每 5 秒及关键操作后在后台保存，退出时等待最后一次写入完成。保留一份上次可读取的存档备份；主存档损坏时尝试恢复。达到 2048 后仍可继续。
- 滑动采用起止速度与加速度连续的曲线；合并有轻微回弹与亮度反馈，新方块淡入，鼠标悬停有局部玻璃反光。
- 正常滑动按距离耗时约 165–205 ms；合并回弹不再阻塞下一步，连续输入可暂存 4 个方向。

## 动画与帧率

方块材质在启动和切换外观时预先生成，滑动途中不会重新生成或跨格变色。分数与按钮悬停使用按时间计算的过渡。AI 在当前动画播放时预先计算下一步，暂停、撤销或手动接管会丢弃过时结果。

优先由实际生效的垂直同步控制帧率。如果连续观察到系统虽然报告开启垂直同步，但绘制仍迅速返回，会启用按显示刷新率计算的限帧；同步重新实际阻塞时停止额外限帧，避免两个定时器叠加。第八版在当前 75 Hz 环境复测；第六版曾在 60 Hz 环境采样，手动和自动均平均 16.67 ms。尚未在 120 Hz 屏幕实测。

面板保留约 180 ms 的虚化与缩放过渡，以及按钮按压反馈、延迟悬停提示。当前帧率采样及首次打开面板的开销见 `测试报告.md`。

## 自动玩与分析

设置里的 **快速 / 标准 / 深入** 对应每步约 25 / 100 / 450 毫秒的搜索预算。**自适应**以 120 ms 为基础，根据空格数给出约 90–300 ms 的硬预算，并可在方向稳定时提前返回。教练采用更轻量的预算。**慢速 / 正常 / 快速**调节对局节奏；**冲分**跳过逐步动画。具体耗时随机器负载变化。

每次启动，搜索核心会在后台准备数秒，期间可以手动操作。在「查看 AI 分析」中，可以重新计算四个方向，查看相对局面评分、搜索深度、局面数量和耗时。细条不是胜率，终局风险只计算下一次随机落子，不预测后续整局失败概率。

第八版根据已完成深度的结果排列下一层搜索方向，不将半次根节点搜索作为最终四方向评分。如果一个方向在下一次落子后必定结束，而另一个有存活可能，会避开必败方向。最近 32 个相同棋盘、相同预算的分析可以复用；「重新分析」强制重新计算。局面说明来自合并、空格、角落等可检查事实，不冒充完整搜索推理。

下面的本机编译搜索用于经典、每日同局与冲刺。解局和重生使用各自的确定性求解器，远征使用上文所述的规则感知搜索。经典搜索是概率加权 Expectimax 的强化实现，未训练神经网络，也不声称绝对最优：

1. Python 数值内核经 Numba 编译为本机机器码。
2. 80 位双字棋盘，每格 5 位，百万行状态预计算。
3. 逐层加深，动态低概率分支裁剪，拥挤局面更谨慎。
4. 524,288 项局面缓存，验证完整棋盘、搜索深度、概率键，避免哈希碰撞错误。
5. 改进的合并潜力估值与有限终局惩罚，避免极小概率坏结果支配决策。
6. 32768 之后继续完整搜索，不再切回单步策略；AI 编码支持至 2³⁰ 的方块。
7. 独立进程运算，搜索不会占用界面的 Python 执行线程。

以下是第一版与第二版的历史完整对局基准：相同三个随机种子、相同每步 25 ms 预算。

| 种子 | 旧版分数 | 新版分数 | 新版最大方块 |
|---:|---:|---:|---:|
| 42 | 133,316 | 491,144 | 32,768 |
| 7 | 78,172 | 386,964 | 16,384 |
| 2048 | 71,528 | 176,192 | 8,192 |
| 平均 | 94,339 | 351,433 | — |

当时三局均分约为第一版的 3.73 倍。样本较小，结果随随机落子和机器负载变化，不保证每局相同。原始日志见 `validation/v2/`。第八版完成了局面抽查，没有重新运行整局高分对照，不声称新功能进一步提高了平均分；当前检查见 `测试报告.md`。

## 工程结构

- `game.py` / `desktop_start.py`：桌面启动、Windows DPI / 缓存配置、重复启动保护和错误日志。
- `platform_paths.py`：系统对应的存档位置、旧 Windows 存档迁移与进程锁。
- `check_runtime.py` / `check-windows.bat`：离线依赖、资源、持久化与后台 AI 自检。
- `tools/build_windows.py`：校验下载内容，组装可重定位的 Windows 便携包并审核 PE 依赖。
- `air_ui.py`：悬浮界面、方块、动画、输入与磨砂面板。
- `typography.py`：系统字库查找、真实字重选择、共同光学行框。
- `features.py`：教练、分析预览、模式选择与复盘界面。
- `adventures.py`：精选大厅、能力选择、主动能力、个人残局与路线对照。
- `expedition.py`：六关远征规则、九种能力与独立的规则感知 AI。
- `rescue.py` / `rescue_practice.json`：真实败局提取、随机状态重放、最短解搜索与三个练习样本。
- `journey.py`：模式大厅、章节、星级、限步结算与独立成绩。
- `puzzles.py` / `puzzle_levels.json`：固定残局、可复现落子与精确最短路径搜索。
- `modes.py`：每日种子、独立存档与只读时间线。
- `insight.py`：可检查的走法信息与单次落子风险。
- `motion.py`：滑动曲线、合并和生成效果、帧间隔控制。
- `clear_material.py`：低对比环境光、透明材质和边缘折射。
- `ui_core.py`：复用的控制面板与游戏控制器。
- `prism.py`：接触阴影和局部高光等共用绘图函数。
- `interface_base.py`：事件、持久化、音效、后台进程通信及绘图基础。
- `engine.py`：游戏规则、持久化撤销与重做、压缩历史及存档恢复。
- `persistence.py`：合并待写入的快照，在后台线程压缩、备份并同步磁盘。
- `ai.py` / `search_native.py`：搜索服务与本机编译内核。
- `ai_legacy.py`：第一版参考实现，用于规则和算法对照。
- `tests/`：规则、位棋盘、搜索和 UI 集成测试。
- `validation/`：测试记录；当前版本报告见 `测试报告.md`。
