# 第五版测试报告

日期：2026-09-24。当前 Apple Silicon Mac、Python 3.12.9、pygame-ce 2.5.8。

## 界面

按照用户选择的 Apple / visionOS 方向实现中央悬浮棋盘、分数胶囊、浮动操作栏、SF 数字字体、柔和色彩、深浅外观和磨砂设置面板。背景由低对比环境光计算得到，不使用图片壁纸。

实际检查了示例棋盘、初始棋盘、深色外观、设置、AI 分析和终局。滑动、合并、悬停提示均为运行中的 Python 界面。

## 验证

15 项规则与 UI 集成测试通过（9.101 秒）。覆盖存档、撤销、随机状态、80 位棋盘、大方块搜索、单步、提示、自动玩暂停、连续按键、重开、深浅外观、设置和分析等面板、窗口坐标映射。另补充了新棋盘范围内的鼠标拖动、缩放后的设置按钮点击和 Esc 关闭检查。

2160 × 1640 内部画布，每种情况取样 120 帧：

| 场景 | 平均每帧 | 95% 分位 |
|---|---:|---:|
| 静止与悬停 | 5.93 ms | 8.28 ms |
| 移动动画 | 4.86 ms | 5.78 ms |

这是绘制耗时，不代表显示器刷新率。主循环目标为 60 FPS。原始记录在 `validation/v5/render.json`。

搜索核心未修改。第二版完整三局实测为 491144 / 386964 / 176192 分，最大方块为 32768 / 16384 / 8192，有限样本不保证每局表现。日志在 `validation/v2/`。

更新保留用户存档、运行环境和导出图片，旧代码备份至 `backups/v4-source/`。
