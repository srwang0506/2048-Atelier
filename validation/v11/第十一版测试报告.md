# 第十一版：能力远征与绝境重生

2026-09-29，Python 3.12.9、pygame-ce 2.5.8，Apple Silicon Mac。

## 完成内容

- 六关能力远征：九种能力各两级，开局及关卡之间三选一；独立计分、能量、交换、凝时、关卡结算与存档。能力真正改变规则与 AI 评估。
- 绝境重生：在后台从真实经典、每日或冲刺败局提取残局，按原随机状态搜索并重放验证；原局、个人挑战、练习样本、手动 / 辅助成绩分开保存。
- 双路线逐步对照，可比较本次走法、原败局和已验证的最短路线。
- 远征能力卡与升级面板、能量控制、残局库、路线对照，以及深色外观。大厅默认显示排在前面的「经典与挑战」，经典为主入口；「精选玩法」放在后面，收录两个新模式。
- 修复规则集成中的边界问题：最后一步达标判胜、过关不清空最后一枚方块、阻塞局面仍可花费能量、交换完整动画、后台提取结果在切换模式后继续接收、辅助标记不可通过撤销清除、存档快照隔离。

## 完整流程

通过实际应用控制器、后台 AI 进程、绘制与临时磁盘存档进行验证（`validation/v11/full-flow.json`）：

- 远征走完六关，123 次有效移动，6,098 分；在关卡间选择、升级能力，最终持有连击 II、豪赌 I、空间回流 II、角落 I。保存后恢复的完整状态一致。
- 完成一盘真实经典败局，后台生成三步重生挑战，自动玩完成，打开双路线对照，再回到原经典局；原棋盘和随机状态一致，挑战档案、辅助成绩及两个新模式的进度可恢复。

另以三种开局能力各跑一场平衡样本（`validation/v11/balance.json`）：连击 6/6 关、7,210 分；蓄能 5/6 关、4,927 分；豪赌 6/6 关、7,151 分。这是小样本调校，不能据此宣称所有构筑平衡、必定通关或固定游玩时长。限时搜索的结果也可能随机器负载变化。

## 视觉与绘制

导出 16 个实际游戏界面，包括两个大厅、远征介绍、初始能力和升级、对局、交换、能力说明、重新开局、空残局库、练习库、挑战棋盘、完成、路线对照及两个深色界面。检查 541 组文字 / 字号 / 字体组合，无缺字和字形裁切；已查看实际布局。记录见 `validation/v11/render-check.json`。

SDL dummy 驱动下，稳定绘制耗时中位数 5.25 ms、P95 6.47 ms。完整流程绘制中位数 6.18 ms、P95 7.44 ms、最大 49.78 ms。这些只是无窗口环境的 CPU 绘制耗时，不是原生屏幕帧率，也不代表所有首次操作都无延迟。此轮未复测原生窗口帧率、120 Hz 显示器、Windows 或 Linux 外观。

可在项目目录运行 `python -m unittest discover -s tests -v`。`validation/v11/full_flow.py` 与 `render_check.py` 可复现应用流程和渲染检查；渲染预览写入 `validation/v11/previews/`。这些脚本使用示例或临时存档，不读取个人对局。
