# 第十版：字体与布局

2026-09-29，Python 3.12.9、pygame-ce 2.5.8，Apple Silicon Mac。

## 完成的调整

- 增加 `typography.py`，从安装的 TTC 字库选择苹方 SC Regular、Medium、Semibold 的实际字体面。数字使用 Helvetica Neue Medium，2048 标志使用 Bold。没有对中文做伪粗体处理。
- 文字采用共同的光学行框与基线，调整正文和辅助文字对比度。标题、操作、正文有明确字重区别。
- 大厅改为左侧经典主卡、右上解局卡、右下两个紧凑入口。删除英文装饰标签与宣传标语，使用统一的 24 像素间隔与成组对齐。经典插图复用真实棋盘材质并缓存。
- 棋盘右上控件合成一个工具区，底部状态文字共用基线；章节、设置、分析、复盘同步使用新字体。
- 四种模式、原搜索算法、动效、存档与操作保持可用。字体只从本机读取，没有复制系统字体到源码包。

## 功能与渲染检查

58 项既有测试通过，耗时 12.666 秒。覆盖规则、搜索、撤销重做、存档恢复、动画输入、十二章最短解、冲刺上限、四模式保存及 UI 交互。日志：`validation/v10/tests.log`。

另通过真实绘制与指针事件检查四张模式卡：点击区域互不重叠，可以分别进入经典、每日、冲刺与章节；返回经典后棋盘、分数、步数和随机状态保持一致。

导出 14 个实际渲染界面：大厅、经典棋盘、设置、帮助、战绩、重开、复盘、章节、解局棋盘、解法、完成画面、冲刺、深色大厅、深色设置。对绘制过程中使用的 355 组文字与字号组合检查缺字和字形范围，没有缺字或字形裁切。记录：`validation/v10/render-check.json`。

这些图像来自 Python 游戏渲染器和 SDL dummy 显示驱动，并非设计稿。本轮没有做原生窗口显示帧率复测，没有重跑整局高分基准，也未验证 Windows、Linux 的字体外观。

## 安装

只更新源码和说明，保留 `data/`、`.venv/`、`exports/`。原源码备份至 `backups/v9-source/`。安装后的文件校验与存档检查记录在 `validation/v10/deploy.json`。

若旧窗口仍开着，需要关闭后重新双击 `启动游戏.command`；已经运行的 Python 进程不会自动载入新界面。
