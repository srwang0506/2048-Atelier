# はじめに・操作ガイド

対象：LUMINA Native 1.0.1、iPhone / iPad 用プロジェクト。更新日：2026-09-29。**現在のアプリ画面は中国語です。** 本書では日本語の説明に中国語のボタン名を併記します。日本語の説明書があることと、アプリの日本語表示に対応していることは別です。アプリ内の言語切り替えは未実装です。

## 最初の一局

1. ソースコードを受け取った場合は、先に[インストールとビルド](06-build.md)を確認してください。ソース ZIP を iPhone に直接インストールすることはできません。署名済み IPA や TestFlight 招待は今回の配布物に含まれません。
2. 起動すると「经典 2048」（クラシック）が開きます。保存済みのクラシックがあればその続きを表示します。他のモードの進行状況も残りますが、前回遊んだ別モードが起動時に自動で開くわけではありません。
3. **盤面の内側**を上下左右にスワイプします。一つのタイルをつかんで動かすのではなく、盤面全体をその方向へ動かします。
4. 同じ数字がぶつかると合体します。スコアと手数の変化を確認しましょう。
5. 上部のモード名と下向き矢印を押すと、六つのモードを選べます。クラシックが先頭です。
6. アプリから離れると保存が要求されます。機種変更やアンインストールの前には、手動バックアップも書き出してください。

| 中国語の表示・位置 | 日本語での意味 | 動作・注意点 |
| --- | --- | --- |
| 上部のモード名 | 現在のモード | モード選択を開く。切り替え時に進行状況を保存し、AI を停止 |
| 右上のスライダーアイコン | 設定 | 外観、音、触覚、動き、AI、記録、バックアップ |
| 本局得分 | この局のスコア | 合体で得た合計点。最大タイルとは別で、戻すと点数も戻る |
| 手动最高 / 辅助最高 | 手動 / アシストの最高記録 | モード別・区分別。操作を戻しても最高記録は下がらない |
| 步数 / 剩余步数 | 手数 / 残り手数 | 有効な方向移動を数える。遠征の能動能力は手数を消費しない |
| 曲がった戻る矢印 | 一手戻す | 前の操作へ戻す。戻す・やり直す履歴の合計は最大 100 件 |
| 提示、または電球 | ヒント | 要求した時点でアシスト扱いになる |
| 走这一步 | この手を実行 | ヒントの提案を実行 |
| 自动玩 / 暂停 | 自動プレイ / 一時停止 | AI に連続して操作させる、または止める |
| 三点メニュー | その他の操作 | やり直し、最初から、モード選択。モード固有の項目も表示 |
| 手动局 / 辅助局 | 手動の局 / アシストの局 | 一度アシストを使うと、この局では手動区分に戻らない |

## タッチ操作とキーボード

盤面内をはっきり上下左右にスワイプします。斜めの場合は移動量の大きい軸が採用され、短すぎる動きは無視されることがあります。外付けキーボードは矢印キーと **A＝左、W＝上、D＝右、S＝下** に対応します。その他のショートカットは未実装です。Cmd+Z で戻せるとは限りません。

アニメーション中に待機させられるスワイプは最大二つです。非常に速い連続入力を無制限に蓄積することはありません。正確に操作したいときは、一手が落ち着いてから次を入力します。

シート、警告、再開始の確認が開いたときやバックグラウンドに移ったときは、待機中の入力を破棄して AI を停止します。戻った後は手動で動かすか、再度「自动玩」を押してください。

遠征の交換は「交换」を押し、数字が異なる二枚のタイルを順に選びます。最初に選んだタイルをもう一度押すと選択解除。「取消」で交換モードを終了します。

## 戻す・やり直す・最初から

**一手戻す（撤销一步）**は、盤面、乱数状態、スコア、手数、遠征状態を復元します。同じ操作を再び行えば同じ出現結果になります。戻す操作で都合のよい乱数を引き直すことはできません。凝時と交換も各一件の履歴を作ります。

**やり直す（重做一步）**は三点メニュー内です。戻した後に新しい有効な操作をすると、以前のやり直し分岐は消えます。遠征で最初の能力やステージ間報酬を選ぶと履歴が消えるため、前ステージに戻って報酬を選び直すことはできません。

**最初から（重新开始）**には確認があります。現在のモードの進行中の局だけを置き換えます。クラシック、スプリント、遠征は新しいランダム開始、パズルとレスキューは同じ問題の開始状態、デイリーは現在開いている日付の開始状態に戻ります。最高記録と取得済みの星は残ります。昨日のデイリーを開いている場合、今日を始めるにはモード一覧から「每日同局」を選び直します。

## iPhone と iPad の配置

狭い画面ではタイトル、スコア、盤面、操作、説明を縦に並べます。横幅がある場合は盤面が左、情報が右です。高さの少ない横画面では情報欄をスクロールできます。iPad は利用可能な幅に合わせて配置しますが、二つの独立した局を同時表示する機能ではありません。回転や Split View の移行は実機での確認が必要です。

## 設定一覧

| 中国語の項目 | 選択肢・初期値 | 用途 |
| --- | --- | --- |
| 外观 | 跟随系统＝システム連動、浅色＝ライト、深色＝ダーク | 初期値はシステム連動 |
| 声音 | サウンド、初期値オン | 移動と合体の音。システムの音量・出力状態にも依存 |
| 轻触反馈 | 触覚フィードバック、初期値オン | 対応ハードウェアが必要。一部 iPad では利用不可 |
| 减少动态效果 | 動きを減らす、初期値オフ | タイルの動きを抑える。システム設定も反映 |
| 思考强度 | 灵敏＝軽快、深度思考＝深い思考 | 初期値は軽快。深い思考は探索時間を増やす |
| 自动游玩节奏 | 自動プレイ間隔、0.20～1.50 秒、初期値 0.42 秒 | 探索・アニメーション込みの実時間を保証する値ではない |

## アクセシビリティ

盤面の各マスには行、列、数字または空白の読み上げラベルがあり、盤面に四方向のアクセシビリティ操作を用意しています。交換対象も選択可能です。現状の読み上げは中国語です。必要に応じて動きを減らす設定を使ってください。VoiceOver の一連の操作、大きな文字サイズ、キーボードのフォーカスは iOS 実機で未検証です。問題は[報告用テンプレート](05-faq.md)に沿って記録してください。
