# よくある質問・不具合の報告

## 動かない、押しても反応しない

メニュー、警告、報酬選択、終了状態になっていないか確認してください。移動で盤面が変わる方向だけが有効です。盤面の中から十分な距離をスワイプします。動作中の待機入力は最大二つで、それ以上を蓄積しません。狭い画面の電球はヒントです。

「准备棋盘…」のままの場合は、内蔵問題の読み込みエラーがないか記録し、閉じて開き直します。開発者はリソースの同梱を確認してください。未バックアップの進行状況を、調査のためだけにアンインストールしないでください。

## 2048 を作っても終わらない

クラシックとデイリーはそれ以上を目指せます。パズルは指定数字、スプリントは手数、遠征はステージ得点で判定します。終了条件はモード別です。

## 合体したのにレスキューが成功しない

通常は合体の後に新タイルが一枚出ます。レスキューはその後の空き数を数えるので、合体直後に三つあっても二つに戻る場合があります。新タイルを抑える凝時と空間還流は遠征だけです。

## いつの間にかアシスト扱いになった

ヒント要求、自動プレイ、クリア前のレスキュー比較リプレイでアシスト扱いになります。提案を採用しなくても同じです。戻すやバックアップ読み込みでは消えません。以前の手動最高点は残りますが、この局のその後の点数はアシスト区分へ記録されます。

## 星三つにならない

標準手数以内、アシストなし、戻す未使用の全条件が必要です。標準手数と最大手数を混同しないでください。戻すを使えば未アシストでも最大二つ、アシスト後のクリアは一つです。新しく挑戦するにはその問題を最初から始めます。

## AI が止まる、AI でも負ける

報酬、終了、メニュー、手動介入で止まります。メニューを閉じた後は再度自動プレイを押してください。有限時間の探索と評価なので、ランダムな局で無限に生き残る保証はありません。深い思考は探索予算を増やすもので、完全最適解の証明ではありません。遠征の報酬は自分で選びます。

## 遠征の能力が灰色になる

凝時は 5 エネルギー、冷却なし、凝時中でないこと、移動できる盤面が必要です。交換は必要エネルギーと異なる数字の二枚が必要です。アニメーション中は能力操作を待ちます。エネルギー上限は 12。六手のクールダウンは六秒ではなく、有効移動六回です。

## 友達とデイリー盤面が違う

端末のローカル日付、モード、バージョン、すでに動かした手を確認してください。タイムゾーンによって日付も違います。同じ盤面には同じ操作列が必要で、通信で同期する機能ではありません。昨日の局を開いたままなら、デイリーを選び直して今日の局を開きます。

## バックアップを読めない、古い状態に戻った

| 状況 | 確認・対処 |
| --- | --- |
| 存档格式不正确（形式不正） | このネイティブ版から出した、欠けていない未改変の JSON か確認。デスクトップ等とは非互換 |
| 超过 24 MB（大きすぎる） | 上限 24,000,000 バイト。元を残し、適当な項目を消して縮めない |
| 已从备用存档恢复（予備から復元） | 主ファイルが消失・破損。直近操作のない旧版かもしれないので、新しい手動バックアップがあれば利用 |
| 読み込むとクラシックが開く | 現在の仕様。他のモードを選んで続きへ |
| 二台それぞれで進んだ | 自動統合はしない。両方を先に出力し、どちらを残すか決める |
| 保存失败（保存失敗） | 空き容量を確認し、可能なら出力、エラー全文を記録 |

保存不調の調査中に何度も最初から始め、唯一の利用可能な状態を上書きしないでください。

## 音・触覚・動きが想定と違う

アプリ設定、システム音量、消音、出力先を確認します。実装は他の音と混合できる環境音のカテゴリを使用します。触覚はハードウェア依存で、一部 iPad は同じ振動を出せません。動きを減らす設定はアプリとシステムの両方を確認してください。説明用 GIF はフレームを採取した教材であり、iPhone の実際の更新頻度を評価する材料ではありません。消音、触覚、フレームレートは実機検証待ちです。

## iPhone / iPad にどう入れるのか

ソース ZIP、Xcode プロジェクト、macOS プレビューはインストール可能な IPA ではありません。完全な Xcode、対応 SDK、署名設定が必要です。現状 TestFlight 招待はありません。[導入手順](06-build.md)を参照してください。

## 英語・日本語画面、Windows、通信対戦はあるか

本書は三言語ですが、現在のアプリ表示は中国語で、言語切り替えボタンはありません。以前の Python デスクトップ、Windows、PWA 版は独立して残っています。本書はそれらを iOS アプリとして扱わず、保存形式や全機能の一致も保証しません。ネイティブ版には通信対戦、クラウドランキング、自動クラウド同期はありません。

## 伝わる不具合報告

次の項目をコピーし、どの操作の直後に起きるかを具体的に書いてください。

| 項目 | 記入例 |
| --- | --- |
| バージョン | 1.0.1 Native とビルド番号 |
| 端末・OS | iPhone / iPad の機種、iOS / iPadOS のバージョン |
| モード・場所 | パズル 03、遠征第 2 ステージなど |
| 再現手順 | 起動 → モード選択 → 左へ → 戻す → 現象 |
| 期待 / 実際 | どうなるはずで、実際はどうなったか |
| 頻度 | 毎回、または何回に一回程度か |
| 状態 | AI、動きを減らす、キーボード、Split View |
| 証拠 | 画像 / 動画、エラー全文。必要なら共有してよいバックアップ |

アプリ内の問い合わせ送信ボタンや、指定の公開サポートメールはありません。上記をプロジェクト管理者へ渡してください。[バージョンと検証範囲](09-release.md)にも未確認事項を記載しています。
