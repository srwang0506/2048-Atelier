# 开始游玩与完整操作

适用：LUMINA 原生版 1.0.1，iPhone / iPad 工程。文档更新：2026-09-29。App 当前按钮为中文；英文和日文手册提供按钮对照。文档语言与 App 界面语言是两件事，目前没有 App 内语言切换器。

## 第一次打开

1. 如果拿到的是源码包，先看[安装与构建](06-build.md)。源码 ZIP 不能直接在 iPhone 上安装；当前交付没有已签名 IPA 或 TestFlight 链接。
2. 启动后默认进入**经典 2048**。如果已有经典存档，会继续该局。其他模式仍保留，但启动时不会自动返回上次选中的其他模式。
3. 在棋盘区域向左、上、右或下滑动。一次滑动让整盘方块朝该方向移动，不需要抓住某一块拖动。
4. 相同数字相撞会合成一个更大的数字。观察“本局得分”和“步数”。
5. 想换玩法，点顶部的模式名称与下拉箭头。经典是列表第一项。
6. 想停下来，直接离开 App；程序会请求保存。换设备或卸载前，请主动导出备份。

## 屏幕上每一部分的含义

| 位置 / 控件 | 用途 | 需要知道的细节 |
| --- | --- | --- |
| 顶部模式名称 | 打开六种玩法列表 | 换模式会保存当前局并停止 AI |
| 右上角滑杆图标 | 设置 | 外观、声音、触感、动态效果、AI、记录、备份 |
| 本局得分 | 当前局合并所得总分 | 不是最大方块的数字；撤销会恢复分数 |
| 手动最高 / 辅助最高 | 当前模式对应类别的历史最高分 | 最高纪录不随撤销下降 |
| 步数 / 剩余步数 | 已完成的有效移动或该模式剩余次数 | 无效滑动不扣步数；远征主动能力不扣移动步数 |
| 棋盘 | 四向滑动与交换时选格 | 滑动应从棋盘内开始，避免与页面滚动混淆 |
| 回转箭头 | 撤销一步 | 返回上一条操作记录，最多保留 100 条撤销 / 重做历史 |
| 提示 / 灯泡 | 搜索下一步 | 仅请求提示也会立即标记辅助局 |
| 自动玩 / 暂停 | 开始或停止自动游玩 | 手动滑动也会停止 AI |
| 三点“更多” | 重做、重新开始、模式列表等 | 谜题模式增加“选择谜题”；残局增加“残局档案”“对照复盘” |
| 棋盘下方说明 | 目标、AI 状态、提示卡片、关卡结果 | 小屏可上下滚动查看 |
| 底部手动局 / 辅助局 | 当前局记录类别 | 开过辅助后，撤销、重做或手动接管都不会恢复手动类别 |

## 手势、键盘与连续输入

- 在棋盘内做清晰的水平或垂直滑动。斜向滑动按位移更大的轴处理。
- 外接键盘支持方向键和 WASD：A 左、W 上、D 右、S 下。键盘其他快捷键没有实现，不应假定 Cmd+Z 能撤销。
- 动画期间最多排队两次滑动；极快连续输入不会无限积压。要精确控制，可等这一步落定再滑。
- 打开页面、出现提示 / 重开确认或进入后台时，排队的动作会被清空，AI 停止。返回后手动操作，或再次点“自动玩”。
- 交换能力先点“交换”，再依次点两枚不同数字且非空的方块；再次点第一枚可取消该枚选择。点“取消”退出交换。

## 撤销、重做与重新开始

**撤销**恢复棋盘、随机数状态、得分、移动步数和远征状态。随机数状态也被恢复，因此撤销后重复相同动作不会重新抽一个更有利的落子。远征的凝时与交换也各占一条可撤销操作记录。

**重做**在三点菜单中。撤销后如果执行了新的有效操作，旧的重做分支会被清空。远征选择初始能力或关间奖励后会清空历史，不能撤销到上一关重新选奖励。

**重新开始**有确认提示，只替换当前模式的当前局。经典、冲刺和远征会重新生成随机开局；谜题与残局重置当前题；每日重置当前打开日期的相同起点。已有最高分和谜题最佳星级保留。要玩新一天的每日局，请从模式列表重新选择“每日同局”。

## iPhone 与 iPad 布局

窄屏把标题、得分、棋盘、操作和说明纵向排列；宽屏把棋盘放在左侧，信息放右侧。较矮的横屏会滚动显示侧栏内容。iPad 可按可用窗口宽度调整布局；这不是同时玩两局。旋转或分屏调整的设备行为仍需要真机验收。

## 设置建议

| 设置 | 默认 / 可选项 | 用途 |
| --- | --- | --- |
| 外观 | 跟随系统；可选浅色、深色 | 改变界面配色 |
| 声音 | 默认开启 | 移动与合并反馈，受系统音量 / 音频环境影响 |
| 轻触反馈 | 默认开启 | iPhone 等具备相应硬件的设备提供触感；部分 iPad 不支持 |
| 减少动态效果 | 默认关闭 | 缩减棋子动效；系统的减少动态效果也会生效 |
| 思考强度 | 灵敏；可选深度思考 | 更长的本地搜索预算，不保证固定胜率 |
| 自动游玩节奏 | 默认 0.42 秒，可调 0.20–1.50 秒 | 这是节奏设置，实际每步还受搜索和动画耗时影响 |

## 无障碍

棋盘提供行、列和数值的语音标签及四向移动的无障碍动作；空格也有标签。交换时格子可作为可选控件。减少动态效果可以在 App 设置中开启。当前语音标签是中文。完整 VoiceOver 流程、动态字体大字号和硬件键盘焦点尚未做真机验收；如有问题，请按[问题反馈格式](05-faq.md)记录设备与具体操作。
