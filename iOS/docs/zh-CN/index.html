开始游玩与完整操作

适用：LUMINA 原生版 1.0.1，iPhone / iPad 工程。文档更新：2026-09-29。App 当前按钮为中文；英文和日文手册提供按钮对照。文档语言与 App 界面语言是两件事，目前没有 App 内语言切换器。

第一次打开

  1. 如果拿到的是源码包，先看安装与构建。源码 ZIP 不能直接在 iPhone 上安装；当前交付没有已签名 IPA 或 TestFlight 链接。
  2. 启动后默认进入经典 2048。如果已有经典存档，会继续该局。其他模式仍保留，但启动时不会自动返回上次选中的其他模式。
  3. 在棋盘区域向左、上、右或下滑动。一次滑动让整盘方块朝该方向移动，不需要抓住某一块拖动。
  4. 相同数字相撞会合成一个更大的数字。观察“本局得分”和“步数”。
  5. 想换玩法，点顶部的模式名称与下拉箭头。经典是列表第一项。
  6. 想停下来，直接离开 App；程序会请求保存。换设备或卸载前，请主动导出备份。

手势、键盘与连续输入

  • 在棋盘内做清晰的水平或垂直滑动。斜向滑动按位移更大的轴处理。
  • 外接键盘支持方向键和 WASD：A 左、W 上、D 右、S 下。键盘其他快捷键没有实现，不应假定 Cmd+Z 能撤销。
  • 动画期间最多排队两次滑动；极快连续输入不会无限积压。要精确控制，可等这一步落定再滑。
  • 打开页面、出现提示 / 重开确认或进入后台时，排队的动作会被清空，AI 停止。返回后手动操作，或再次点“自动玩”。
  • 交换能力先点“交换”，再依次点两枚不同数字且非空的方块；再次点第一枚可取消该枚选择。点“取消”退出交换。

撤销、重做与重新开始

撤销恢复棋盘、随机数状态、得分、移动步数和远征状态。随机数状态也被恢复，因此撤销后重复相同动作不会重新抽一个更有利的落子。远征的凝时与交换也各占一条可撤销操作记录。

重做在三点菜单中。撤销后如果执行了新的有效操作，旧的重做分支会被清空。远征选择初始能力或关间奖励后会清空历史，不能撤销到上一关重新选奖励。

重新开始有确认提示，只替换当前模式的当前局。经典、冲刺和远征会重新生成随机开局；谜题与残局重置当前题；每日重置当前打开日期的相同起点。已有最高分和谜题最佳星级保留。要玩新一天的每日局，请从模式列表重新选择“每日同局”。

iPhone 与 iPad 布局

窄屏把标题、得分、棋盘、操作和说明纵向排列；宽屏把棋盘放在左侧，信息放右侧。较矮的横屏会滚动显示侧栏内容。iPad 可按可用窗口宽度调整布局；这不是同时玩两局。旋转或分屏调整的设备行为仍需要真机验收。

游戏规则：从合并到六种玩法

所有模式共用的棋盘规则

棋盘为 4 × 4，共 16 格。每次选择一个方向，所有方块都向该方向滑到不能再滑的位置；相邻的相同数字成对合并。本次刚合成的方块不会在同一步再次合并。

以下示例只展示一行向左移动后的合并结果，尚未加入新方块：

移动前 向左后 合并基础分
2 · 2 · 0 · 0 4 · 0 · 0 · 0 4
2 · 2 · 2 · 0 4 · 2 · 0 · 0 4
2 · 2 · 4 · 0 4 · 4 · 0 · 0 4，不会直接变成 8
2 · 2 · 2 · 2 4 · 4 · 0 · 0 8
4 · 4 · 8 · 8 8 · 16 · 0 · 0 24
2 · 4 · 8 · 16 不变 0，整盘也不变时属于无效移动

一次移动只要整盘发生变化，就是有效移动：增加一步，并通常在一个空格生成新方块。标准生成概率为 2 占 90%、4 占 10%；远征能力可以改变概率或取消落子。只移动位置而没有合并也会生成方块、消耗一步，但得分为 0。无效移动不计步、不落子，也不推进随机状态。

分数是每组合并结果数值之和，远征再应用能力加成。最大方块是棋盘里最大的一枚，和总分是不同指标。棋盘填满且横竖方向都没有相邻相同数字时，通常无路可走；远征还会检查是否有可用主动能力。

经典 2048

经典是默认玩法。开局生成两枚方块。合成 2048 不会强制结束，也不弹出必须停下的胜利流程，可以继续合成 4096 或更高数字。结束后可撤回一步，或在符合条件时提取残局挑战。

入门练习：选定一个角落放最大数字；让相邻行列尽量保持从大到小；移动前先判断是否会把最大数字带离角落；留出空格比每一步都追求眼前分数更有余地。这些是策略建议，不是强制规则，也不保证每一局都能获胜。

每日同局

以设备本地日期的 YYYY-MM-DD 生成固定随机种子。相同日期、相同规则、相同动作序列会重现同样的局面；走不同路线，落子位置会随可用空格变化。它不是联网比赛，没有全球排行榜、倒计时服务器或强制统一时区。

打开的昨日局不会在午夜强制清空。想开始今天的棋盘，从模式列表选择每日同局；仍在昨日局时点重新开始，会重置昨日局。保存最近七个日期的每日进度。手动 / 辅助最高分按整个每日模式累计，并不是每个日期一个独立榜单。

六十步冲刺

只计算有效的四向移动，无效滑动不扣次数。到第 60 步后计算结束；如果更早无路可走则提前结束。它不是 60 秒倒计时，可以停下来思考。撤销会恢复剩余步数，最高纪录不会随之下降。

最后一步只剩即时合并收益，没有第 61 步可供布局。AI 已按这个边界处理。还有剩余步数时，需要在当步得分与后续机会之间取舍。仅仅用满 60 步、但棋盘还可移动的结束局，不符合“真实无路可走”的残局提取条件。

十二道固定棋盘，目标从 64 到 2048。通过“更多 → 选择谜题”任选题目；没有逐关解锁门槛。每题有最大允许步数和标准步数，落子是确定的，重复相同操作会重现结果。

星级按本次完成方式确定，历史只保留更高星级：

  • 三星：未使用辅助、没有撤销、在标准步数以内完成。
  • 两星：未使用辅助并在限制内完成，但超过标准步数，或使用过撤销。
  • 一星：使用提示 / 自动游玩等辅助后完成。

重做不会抹掉“曾撤销”的次数。最后一个允许步数正好达成目标仍判胜利。选择另一题会替换谜题模式的当前进行中棋盘，已取得的各题星级仍保留；不是同时保存十二局进行中状态。解答章另列具体路线。

败局重生

这里的目标是腾出空格，不是合成 2048。达标检查发生在滑动、合并及新方块落下之后。例如合并后有三个空格、随即生成一枚新方块，最后只剩两个空格，就还没有达到“腾出三个空位”的目标。

三道精选残局随 App 提供，均要求六步内腾出三个空格：“一线生机”“腾挪之间”“逆转时刻”。进入残局后，通过“更多 → 残局档案”选择。可撤销、重试、请求提示或自动解题。

生成自己的残局：

  1. 在经典、每日或冲刺中走到棋盘真正无路可走。
  2. 在结果区点“寻找这局的另一种结局”。
  3. 程序检查最后十步中的候选起点，寻找六步内腾出三个空位的可验证路线。候选起点最多只有一个空位。
  4. 找到后点“试着改写这局”，进入独立挑战。原模式的原局保留。
  5. 如果提示未找到，表示此次范围 / 时间限制内没有确认符合条件的转机；不代表数学上证明所有更早局面都无解。

个人残局最多保存六条；新增时会清理较旧且未被当前挑战使用的档案。精选残局不占这六条。只有残局具备双路线逐步复盘，并不是任意经典长局都能播放完整录像。

“对照复盘”可切换原来的路线和转机路线，用上一步 / 下一步逐帧看棋盘。切换路线回到第 0 步。在过关前打开复盘就会标记辅助局，即使只是想看原路线；因为复盘默认展示已验证解法。过关后查看不改变已经完成的本局类别。

能力远征：关卡、能量与九种能力

一次完整远征

进入远征后先三选一：连击引擎、蓄能核心、豪赌协议。选好后开始第一关。每关要求在限定有效移动次数内获得该关目标分数；顶部本局得分是累计值，关卡进度条显示的是当前分数减去进入该关时分数。

关卡 名称 本关目标分 基础移动次数 从容节拍 I / II 后
1 启程 100 26 30 / 34
2 蓄势 260 34 38 / 42
3 回响 520 42 46 / 50
4 临界 900 46 50 / 54
5 跃迁 1400 52 56 / 60
6 终章 2200 60 64 / 68

前五关达标后暂停，出现新的三选一奖励。选择新能力或把已有能力升到 II；满级能力不再被提供。奖励后进入下一关，保留棋盘、累计得分、已选能力与能量；如果棋盘有两枚以上数字，移除一枚最小数字，给下一关腾出空间。最小值并列时取棋盘从左上到右下的第一枚。

关间不结转未使用的移动次数，也不把上一关超出目标的分数算入下一关进度。连击、凝时剩余次数与冷却在选奖励后归零，历史撤销 / 重做也清空。最后一关达标即赢得整段远征。最后一步达标优先判过关；否则移动次数耗尽，或棋盘不能动且无主动能力可用时失败。

能量与主动能力

每合并一组方块获得 1 点能量，能量最多 12。蓄能核心提高每组收益。纯位移无合并不产能量。能量只在远征内存在。

主动能力 基础成本 操作 结果
凝时 5 点 点“凝时 · 5” 接下来两次有效移动不生成新方块；立即设置六步冷却
交换 6 点 点交换，依次点两枚不同数值的非空方块 交换两者位置，不合并、不生成新方块

两种能力都不扣移动步数，不直接得分，但各自会生成撤销记录。交换不能选空格或两枚相同数字。能量不足时按钮不可用。凝时要求尚未处于凝时、冷却为 0 且棋盘仍可移动；它不能直接解救一张已经完全卡死的棋盘，交换有时可以。

冷却和凝时剩余次数只随有效移动递减，等待、无效滑动、使用交换不会推进。凝时期间若某步也触发空间回流，该步仍会消耗一次凝时次数；不是把次数留到下一步。每次换关会重置凝时与冷却。

连击与得分怎么算

连击是连续的“有合并的有效移动”，不是同一步合并了多少组。无效滑动不打断；纯位移的有效移动会打断。主动能力不推进 / 打断连击。

设基础合并分为 G，角落奖励为 C，共鸣奖励为 E：

本步得分 = (G + C + E) × 连击倍率 × 豪赌倍率

最后四舍六入五取偶到整数，即正好 .5 时取最近的偶数。举例：基础合并分 24，其中角落生成 8，有两组合并；持有角落 I、共鸣 I、连击 I 且处于第二次连续合并、豪赌 I，则本步为 (24 + 4 + 12) × 1.25 × 2 = 100 分。

连击 I 从连续合并第 1–5 次的倍率依次为 1、1.25、1.50、1.75、2；以后仍为 2。连击 II 为 1、1.40、1.80、2.20、2.60，以后仍为 2.60。

三种练习思路

能量路线：蓄能核心配折跃透镜，增加可以交换整理棋盘的机会。注意能量接近 12 时继续合并可能溢出，适时使用能力。

多组合并路线：共鸣回路配空间回流，计划一步合并两组以上，同时得分和减轻空间压力。不要为了触发能力做破坏布局的无效准备。

倍率路线：连击引擎配豪赌协议，可更快接近关卡目标，但更高的 4 概率和维持连击的需求会增加规划难度。不要把“豪赌”误认为免费翻倍。

以上是练习方向；每次奖励只从当前三项选一，不保证恰好抽到理想组合。AI 可在局内使用能力，但不会替你选关间奖励。录制示例见远征动图。

智能助手、记录与存档

提示与自动游玩的区别

点“提示”只计算建议，不自动执行。提示卡显示方向或能力，点“走这一步”才执行；也可自行滑动。点“自动玩”则连续计算并执行，按钮变成“暂停”。手动滑动、撤销、重做、换模式、打开设置、弹窗、切后台或换关选能力都会停止自动游玩。关闭菜单后不会自动恢复，需再次点按钮。

请求提示本身就将当前局标记为辅助局，即使没有按建议行动；开启自动游玩也一样。残局过关前打开对照复盘也会标记。关闭 AI、撤销、导出再导入都不会把这一局变回手动局。重新开始新的一局才重新按未辅助状态计。

算法实际做什么

模式 实现 输出如何理解
经典、每日 Expectimax 概率搜索 比较移动与随机落子后的后续局面，倾向空格、可合并数字、平顺排列和大数字靠角
冲刺 带剩余移动范围的概率搜索 不搜索超出剩余步数的假想机会；最后一步以即时分数比较
远征 概率搜索 + 能力收益处理 考虑能力的得分和落子影响；以启发式选择交换 / 凝时；不是所有能力组合的全局穷举
谜题、残局 带完整随机状态的广度优先搜索 按由短到长的路线搜索，找到时给出可重放的最短解；有搜索时间上限

经典搜索使用行表预计算、重复状态缓存、逐层加深和极低概率分支截断。界面中的“优先 / 备选”是搜索排序，不是获胜概率或保证得分。普通模式不读取未来随机序列来作弊；谜题 / 残局为了可复现解法使用它们的确定随机状态。

“灵敏”的通常搜索预算为约 0.14 秒，“深度思考”为约 0.55 秒；这是算法预算而非每步端到端延迟承诺。谜题 / 残局会至少分配约 1 秒搜索预算。更深搜索可能增加耗电与发热，也不保证永远选到最优解。超时与确认搜索范围内无解是不同结果；出现“搜索未完成”可重试或撤销。

如何看 AI 演示

先在经典点提示，比较它给的方向与自己的想法，再点走这一步。开启自动玩观察它如何保留空位。把节奏调慢便于学习。远征到达奖励选择时会停下来；选择后重新点自动玩。追求手动纪录时请从一开始就不使用辅助。

已有固定种子的主机检查：经典 3,200 步、69,592 分、最大 4096（1.0 历史检查）；1.0.1 远征六关通过，138 次动作、6,422 分。这只是具体一局的结果，不是设备跑分、平均胜率或高分承诺。

记录与星级

每种模式分别保存手动和辅助最高分；日常局的纪录按整个每日模式累计。当前局曾经取得的最高分不会因为撤销而被抹去。谜题星级每题取历史最大值，后续一星通关不会覆盖已有三星。App 没有在线排行榜、账户跨设备合并、好友对战或云端战绩。

自动保存包含什么

各模式当前局、棋盘与随机状态、得分、移动次数、辅助标记、撤销 / 重做历史、远征能力、谜题最佳星级、个人残局档案、最高纪录和设置。每个非每日模式保留一个当前会话；每日保留最近七个日期；个人残局档案最多六条。

普通操作合并到约 280 毫秒后开始的写入，持续操作不会无限推迟。进入后台请求立即写入；系统突然终止、空间不足或设备异常仍可能影响最后一次保存，因此重要进度应额外导出。文件采用原子写入，保留上一份可读备用文件；主文件缺失或损坏时会尝试备用文件，损坏原文件另行保留。

导出备份

  1. 点右上角设置。
  2. 找到“进度”，点“导出进度备份”。
  3. 在系统文件面板选择保存位置。默认名称形如 LUMINA-2026-09-29.json。
  4. 确认文件已经出现在“文件”中，再卸载或换设备。
  5. 同一天做多次备份时，为文件加上设备名或时间，避免自己覆盖唯一副本。

导出是一个完整备份，包含设置和各模式进度，不是只有当前一局。通过文件位置选 iCloud Drive 或通过 AirDrop 传输属于手动文件转移，不代表 App 实现了自动 iCloud 同步。

导入与设备迁移

在目标设备安装可运行的原生 App，打开设置 → 导入进度备份 → 选 JSON。程序先检查大小、结构、棋盘、随机状态和挑战等，再询问“用备份替换本机进度？”。确认后替换所有模式的本机进度、纪录和设置，不做两台设备的合并。导入前先导出目标设备的现有进度。

导入完成后先显示经典局，其他模式从模式列表继续。文件无效或超过 24,000,000 字节会拒绝导入；原生备份和 Python 桌面 / Windows / PWA 存档格式不同，不能互导。文件扩展名改成 JSON 并不能转换格式。

本地数据与隐私范围

运行时无服务器依赖，不要求登录，没有广告 SDK。游戏与 AI 在设备本地运行。进度位于 App 沙盒的 Application Support/Lumina，普通玩家通过设置导入导出即可，无需手工改内部文件。备份包含游戏状态和偏好，不包含开发者签名账号。请自行决定要把备份发给谁；分享备份等于分享其中的战绩与进行中局面。

常见问题与问题反馈

点了没有反应 / 方块没动

先看是否在模式菜单、弹窗、选能力或结算状态。在对局中，方向必须能改变棋盘才是有效移动。滑动从棋盘内开始；幅度太小可能被忽略。快速连滑最多排队两次，多出的输入不会继续累积。小屏上的灯泡就是提示按钮。

如果程序显示“准备棋盘”后始终不进入，记录是否出现内置关卡读取错误。先关闭重开；开发者应检查资源是否进入构建。不要为了排查而直接卸载尚未备份的 App。

2048 出现了，为什么没有结束

经典和每日允许继续挑战更大的数字。谜题只检查该题目标；冲刺按步数结算；远征按关卡得分结算。模式不同，结束条件不同。

明明合并了，为什么空格只多一个 / 没达到残局目标

标准模式每次有效移动后还会生成一枚新方块。空格目标按落子后的棋盘计算。远征凝时或空间回流可以取消该次落子；其他模式没有此能力。

为什么突然变成辅助局

请求过提示、开启过自动玩，或者在残局过关前打开过对照复盘，都会标记辅助局。看完提示不用也算。标记不会被撤销或导入去掉。已经取得的手动最高纪录仍保留，之后该局新的分数归辅助纪录。

为什么三星没拿到

检查是否超过标准步数、使用过撤销或任何辅助。标准步数和最大允许步数不同。未辅助但用过撤销，最多两星；辅助完成为一星。想重新挑战三星，重开该题并从头按要求完成。

AI 为什么停了 / 还会输

到达关卡奖励、游戏结束、打开菜单或手动接管都会停。关闭菜单后需重新点自动玩。AI 有限时搜索与启发式评估，随机模式不保证无限生存。深度思考提升搜索预算，不代表数学上全局最优。远征的奖励必须玩家选择。

远征按钮为何灰色

凝时需要至少 5 能量、没有冷却、尚未凝时且棋盘还可移动。交换需要足够能量和两枚不同数字的非空块。动画执行中暂不接受主动能力。能量不会超过 12；凝时冷却不是等六秒，而是六次有效移动。

每日棋盘为什么和朋友不同

核对两人的设备本地日期、模式、版本以及是否已经移动过。跨时区可能日期不同。只有相同日期与相同动作路线才能保证相同局面，不存在联网同步。午夜仍开的昨日局不会自动变成今天，重新选择每日模式即可打开今天的局。

导入失败 / 进度变旧

  • “格式不正确”：确认这是本原生版导出的完整 JSON，且未被截断或修改。Python / Windows / PWA 文件不兼容。
  • “超过 24 MB”：该版本限制为 24,000,000 字节；请保留原文件，避免直接删除内容凑大小。
  • “已从备用存档恢复”：主文件缺失或损坏，已恢复上一份有效数据，可能少最后一次操作。可另行导入较新的手动备份。
  • 导入成功却看见经典：这是当前启动 / 导入行为；切换相应模式查看其他进度。
  • 两台设备都玩过：导入会整体替换，没有自动合并。先分别备份并自行决定保留哪一份。
  • “保存失败”：检查设备存储空间，尝试导出当前进度并记录完整错误。不要反复重开覆盖唯一可用状态。

声音、触感或动画不符合预期

检查 App 设置和系统音量 / 静音 / 音频输出；代码使用允许与其他音频混合的环境音频类别。触感依赖硬件，部分 iPad 没有对应反馈。减少动态效果可能来自 App 或系统设置。文档 GIF 是采样演示，不能用它判断 iPhone 的实际刷新率。真机触感、静音和帧率仍待设备验证。

怎么安装到 iPhone / iPad

源码 ZIP、Xcode 工程和 macOS 预览都不是可直接点击安装的 IPA。需要完整 Xcode、匹配设备的 SDK 和签名配置。当前交付没有 TestFlight 邀请。具体步骤见安装文档。

有没有英文 / 日文界面、Windows 版或联机

本套文档提供中文、英文、日文，当前原生 App 按钮仍是中文。英文 / 日文手册附对应名称；不存在语言切换按钮。以前的 Python 桌面 / Windows / PWA 版本独立保留，本手册不把它们当成 iOS App，也不承诺功能和存档完全互通。原生版没有联机、云排行或自动云同步。

安装、构建与开发者说明

当前交付是什么

LUMINA 1.0.1 是 Swift / SwiftUI 原生 iPhone + iPad Universal App 工程，最低部署 iOS / iPadOS 16.4。没有 WebView。源码包包含独立核心、资源、Xcode 工程、测试、文档与演示媒体。当前没有已签名 IPA、模拟器构建产物或 TestFlight / 商店发布。

最低部署版本不等于任意旧 Xcode 都能构建：Swift 包声明 Swift 工具链 6.0+、Swift 5 语言模式。还需 Xcode 支持目标设备系统。本机只有 Command Line Tools，已完成 macOS 主机检查；未完成 iOS SDK 编译和真机验收。

安装到自己的 iPhone / iPad

  1. 准备 Mac，安装完整 Xcode。按 Apple Xcode 兼容表选择兼容 Mac 与设备系统的版本。不要只安装 xcode-select --install 提供的命令行工具。
  2. 启动 Xcode，完成首次组件安装；在 Settings → Locations → Command Line Tools 选择该 Xcode。
  3. 解压源码到可写的本地目录。双击 Lumina.xcodeproj，选择共享 Scheme Lumina。
  4. Xcode → Settings → Accounts 添加自己的 Apple Account。在 target → Signing & Capabilities 选择自己的 Team；必要时将 Bundle Identifier 改成自己唯一的标识。
  5. 连接并解锁设备，处理系统的信任配对；按 Xcode / 系统提示启用 Developer Mode。在运行目标中选择这台 iPhone 或 iPad。
  6. 点 ▶ Run。第一次构建与签名可能需要等待。失败时先阅读最上面的实际错误，不要把改文件扩展名当成解决办法。
  7. 启动后依次验证经典滑动、横竖屏、所有模式、存档恢复、声音 / 触感和文件导入导出。

Apple 官方：在模拟器或设备运行 App、开发者账户与团队。团队资格与分发要求以 Apple 当时规则为准；不要把个人设备 Run 安装等同于 TestFlight 分发。

版本、验证范围与文档维护

版本标识

游戏：1.0.1 Native，构建号 2。存档结构版本：1。文档修订：2026-09-29。本套说明以当前 Swift 原生代码为准，覆盖六种模式；旧桌面 / PWA 手册不能替代此处的规则和存档说明。

1.0.1 已修复的主要问题

  • 模式菜单、确认弹窗或后台期间，排队输入仍可能继续执行。
  • 连续操作不断推迟写入，主存档缺失时没有尝试备用存档。
  • 损坏原文件可能被覆盖；混合模式状态、非法每日日期与不一致残局可被接受。
  • 冲刺末步搜索了不存在的后续机会。
  • 复盘切换长短路线时旧游标可能越界。
  • 关卡动画期间选择奖励可能残留旧操作。
  • 键盘焦点与后台保存分支已调整，仍需 iOS SDK / 真机验证。

详细触发条件见根目录 BUGFIXES-1.0.1.md。
